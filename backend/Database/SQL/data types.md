
## 🔹 Core SQL Data Types

- **INT** → Whole numbers (e.g., 1, 42, -100)
    
- **DECIMAL** / **NUMERIC** → Fixed precision numbers (e.g., 12.34)
    
- **FLOAT** / **REAL** → Approximate decimals (scientific/large values)
    
- **CHAR** → Fixed-length text (e.g., CHAR(10))
    
- **VARCHAR** → Variable-length text (e.g., VARCHAR(255))
    
- **TEXT** → Large text blocks
    
- **DATE** → Calendar date (YYYY-MM-DD)
    
- **TIME** → Time of day (HH:MM:SS)
    
- **DATETIME** / **TIMESTAMP** → Date + time together
    
- **BOOLEAN** → True/False values
    
- **BLOB** → Binary data (images, files)
