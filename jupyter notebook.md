
1. **Install Jupyter** Inside the environment:
    
    bash
    
    ```
    pip install jupyter
    ```
    
    (Alternatively, you can install `notebook` or `jupyterlab` depending on preference.)
    
2. **Launch Jupyter Notebook** Run:
    
    bash
    
    ```
    jupyter notebook
    ```
    
    This will start a local server and open Jupyter in your default browser at `http://localhost:8888`.
    

## 🔹 Using Jupyter Offline

- **Create notebooks**: Click “New → Python 3” to start a `.ipynb` notebook.
    
- **Run cells**: Use `Shift + Enter` to execute code cells.
    
- **Mix code and notes**: You can write Python code in code cells and explanations in Markdown cells.
    
- **Save locally**: All notebooks are saved as `.ipynb` files in your chosen folder.
    
- **No internet required**: Everything runs locally; only external libraries or datasets need to be installed beforehand.
    

## 🔹 Optional Enhancements

- **JupyterLab**: A more modern interface. Install with:
    
    bash
    
    ```
    pip install jupyterlab
    jupyter lab
    ```
    
- **VS Code integration**: Install the **Jupyter extension** in VS Code, then open `.ipynb` files directly and run cells inside the editor.
    
- **Offline packages**: If your internet is unreliable, download Python packages once and keep them cached locally (e.g., using `pip download`).
    

✅ **Summary for you**: Once you install Jupyter with `pip install jupyter`, you can run it offline by starting `jupyter notebook`. It opens in your browser, lets you mix Python code and Markdown, and saves everything locally.
