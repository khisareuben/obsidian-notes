
## 1. How Custom Transitions Work in `StackView`

The custom transition API relies on 6 properties that target the **entering** and **exiting** views for each of the three transition types (`push`, `pop`, and `replace`):

|**Property**|**Target**|**Description**|
|---|---|---|
|`pushEnter`|Entering Item|The animation applied to the page coming in on a `.push()`.|
|`pushExit`|Exiting Item|The animation applied to the page sliding/fading out on a `.push()`.|
|`popEnter`|Entering Item|The animation applied to the previous page returning on a `.pop()`.|
|`popExit`|Exiting Item|The animation applied to the top page leaving on a `.pop()`.|
|`replaceEnter`|Entering Item|The animation applied to the incoming page on a `.replace()`.|
|`replaceExit`|Exiting Item|The animation applied to the outgoing page on a `.replace()`.|

## 2. Transition Examples

### Style A: The Modern Fade-and-Scale (Sleek UI)

This creates a subtle fade and slight scale-down/up effect instead of the aggressive default sliding.

QML

```JavaScript
import QtQuick
import QtQuick.Controls

StackView {
    id: stackView
    anchors.fill: parent

    // --- PUSH TRANSITIONS ---
    pushEnter: Transition {
        // The entering page fades in and scales up slightly
        NumberAnimation { property: "opacity"; from: 0.0; to: 1.0; duration: 250; easing.type: Easing.OutQuad }
        NumberAnimation { property: "scale"; from: 0.95; to: 1.0; duration: 250; easing.type: Easing.OutQuad }
    }
    pushExit: Transition {
        // The exiting page fades out
        NumberAnimation { property: "opacity"; from: 1.0; to: 0.0; duration: 200 }
    }

    // --- POP TRANSITIONS ---
    popEnter: Transition {
        // The returning page fades back in
        NumberAnimation { property: "opacity"; from: 0.0; to: 1.0; duration: 200 }
    }
    popExit: Transition {
        // The exiting page fades out and shrinks slightly
        NumberAnimation { property: "opacity"; from: 1.0; to: 0.0; duration: 250; easing.type: Easing.InQuad }
        NumberAnimation { property: "scale"; from: 1.0; to: 0.95; duration: 250; easing.type: Easing.InQuad }
    }
}
```

### Style B: The Classic Slide (Directional Customization)

If you want to control the slide-in direction (e.g., sliding vertically from the bottom instead of horizontally):

QML

```JavaScript
StackView {
    id: verticalStack
    anchors.fill: parent

    pushEnter: Transition {
        // Slides up from the bottom of the StackView
        NumberAnimation {
            property: "y"
            from: verticalStack.height
            to: 0
            duration: 300
            easing.type: Easing.OutCubic
        }
    }
    pushExit: Transition {
        // Keeps the background page stationary, just fades out slightly
        NumberAnimation { property: "opacity"; from: 1.0; to: 0.5; duration: 300 }
    }
    
    popEnter: Transition {
        NumberAnimation { property: "opacity"; from: 0.5; to: 1.0; duration: 300 }
    }
    popExit: Transition {
        // Slides back down to the bottom
        NumberAnimation {
            property: "y"
            from: 0
            to: verticalStack.height
            duration: 300
            easing.type: Easing.InCubic
        }
    }
}
```

## 3. Disabling Transitions Entirely

If you want an instantaneous page change with **no animations**, you might be tempted to pass `null` to the transition properties. However, in QML, setting these properties to `null` can trigger race conditions if you make consecutive fast calls (e.g., "cannot push while already in the process of completing a push").

### The Safe Way (App-wide)

To safely disable transition animations globally for the `StackView`, assign **empty Transitions**:

QML

```JavaScript
StackView {
    id: flatStack
    anchors.fill: parent
    
    // Empty transitions disable the default animations safely
    pushEnter: Transition {}
    pushExit: Transition {}
    popEnter: Transition {}
    popExit: Transition {}
    replaceEnter: Transition {}
    replaceExit: Transition {}
}
```

### The Ad-Hoc Way (Per-Action)

If you usually want animations, but need to bypass them occasionally for a specific call, pass `StackView.Immediate` inside your push/pop arguments:

JavaScript

```JavaScript
// Navigates instantly without triggering the transition style
stackView.push("MyPage.qml", StackView.Immediate) 
```

## Python Integration Tip

When using **PySide6**, you do not need to do anything special on the Python side to support these. Your PySide6 `QGuiApplication` or `QApplication` simply loads the QML file via `QQmlApplicationEngine`. All styling, physics, and transitions are managed dynamically by the QML scene graph engine.
