
# 📌 PySide6 + QML CheckBox Notes

## **Purpose**

- `CheckBox` is a standard control for toggling between checked/unchecked states.
    
- Useful for settings, options, and user preferences.
    

## **Basic Usage**

qml

```python
import QtQuick
import QtQuick.Controls

CheckBox {
    text: "Enable feature"
    checked: false
    onToggled: console.log("Checked:", checked)
}
```

- `text` → label displayed next to the checkbox.
    
- `checked` → boolean state (`true` or `false`).
    
- `onToggled` → signal triggered when state changes.
    

## **Properties**

- `checked` → current state.
    
- `text` → label text.
    
- `enabled` → enable/disable interaction.
    
- `tristate` → allows three states: checked, unchecked, partially checked.
    
- `indicator` → customize the checkbox indicator.
    

## **Signals**

- `onClicked` → triggered when clicked.
    
- `onToggled` → triggered when state changes.
    
- Example:
    
    qml
    
    ```python
    CheckBox {
        text: "Dark Mode"
        onToggled: console.log("Dark Mode:", checked)
    }
    ```
    

## **Styling**

- Customize appearance with `indicator` property:
    
    qml
    
    ```python
    CheckBox {
        text: "Custom Style"
        indicator: Rectangle {
            implicitWidth: 20
            implicitHeight: 20
            border.color: "black"
            color: control.checked ? "green" : "white"
        }
    }
    ```
    

## **Example: Multiple CheckBoxes**

qml

```python
Column {
    spacing: 10

    CheckBox { text: "Option A" }
    CheckBox { text: "Option B" }
    CheckBox { text: "Option C"; checked: true }
}
```

- Organize multiple checkboxes in a `Column` or `Row`.
    

## **Best Practices**

- Use `onToggled` for logic instead of `onClicked` (captures state change).
    
- Group related checkboxes in layouts (`Row`, `Column`).
    
- Use `tristate` for hierarchical options (e.g., “Select All”).
    
- Keep labels short and clear.
