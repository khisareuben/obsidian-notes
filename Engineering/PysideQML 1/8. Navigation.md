## 📝 Step 1: Python Backend

For navigation, we don’t need much Python logic yet — just the loader.



```python
import sys
import os
from pathlib import Path
from PySide6.QtGui import QGuiApplication
from PySide6.QtQml import QQmlApplicationEngine

app = QGuiApplication(sys.argv)
engine = QQmlApplicationEngine()

# 1. Find the current absolute directory
CURRENT_DIR = Path(__file__).resolve().parent

# 2. Convert it to a strict file:/// URL (this works on Windows, Mac, and Linux)
#    E.g. "file:///C:/Users/Name/qml_nav/" or "file:///home/user/qml_nav/"
base_url = CURRENT_DIR.as_uri() + "/"

# 3. Inject "baseUrl" directly into QML context
engine.rootContext().setContextProperty("baseUrl", base_url)

# 4. Load main.qml
engine.load(os.fspath(CURRENT_DIR / "main.qml"))

if not engine.rootObjects():
    sys.exit(-1)
sys.exit(app.exec())
```

## 1. What is a StackView?

A `StackView` manages an active stack of pages. Think of it like a deck of cards:

- You only ever see the card on the top of the deck (`currentItem`).
    
- **Pushing** a page adds a new page to the top (sliding it into view).
    
- **Popping** a page removes the top page, destroying it and revealing the page underneath (sliding it out of view).
    

## 2. Core Properties (The Stack's State)

|**Property**|**Type**|**Description**|
|---|---|---|
|`depth`|`int`|The number of pages currently in the stack (starts at `1` with the initial page).|
|`currentItem`|`Item`|The visual item currently active on screen.|
|`initialItem`|`var`|The very first page loaded when the StackView starts up.|

## 3. The 4 Navigation Actions (The "How-To")

### A. `push()` — Go Forward

Pushes a new page onto the stack. You can pass a file name, a QML component, or an already created item.



```JavaScript
// Simple push
stack.push("Page2.qml")

// Push with dynamic data properties (Variables)
stack.push("Page2.qml", { "username": "Alice", "isAdmin": true })
```

### B. `pop()` — Go Backward

Removes the top-most page.

JavaScript

```JavaScript
// Simple pop (goes back 1 page)
stack.pop()

// Pop back to a specific page (skipping pages in between)
stack.pop(null) // Pops all the way back to the very first (initial) page
```

### C. `replace()` — Swap the Current Page

Replaces the top page without increasing the stack's depth. Perfect for login screens where you don't want the user to click "back" and see the login screen again.

JavaScript

```JavaScript
stack.replace("Dashboard.qml")
```

### D. `clear()` — Reset Everything

Empties the entire stack. Typically used when logging out.

JavaScript

```JavaScript
stack.clear()
```

## 4. Master Example: Code Explaining All Features

Here is a complete, single-file runnable example showcasing **custom slide transitions**, **passing data**, and **handling back button states**.

### `main.qml` (The Frame & Animation Settings)

Save this file as `main.qml`. It defines custom sliding animations instead of using the platform's native style.

QML

```JavaScript
import QtQuick
import QtQuick.Controls

ApplicationWindow {
    id: window
    visible: true
    width: 400
    height: 400
    title: "StackView Mastery"

    // Top Header (shows current depth and back-button)
    header: ToolBar {
        Row {
            anchors.fill: parent
            spacing: 10
            
            Button {
                text: "‹ Back"
                // Only show Back button if we have deeper pages on the stack
                visible: myStack.depth > 1 
                onClicked: myStack.pop()
            }
            
            Label {
                text: "Stack Depth: " + myStack.depth
                anchors.verticalCenter: parent
            }
        }
    }

    StackView {
        id: myStack
        anchors.fill: parent
        initialItem: "PageOne.qml"

        // CUSTOM SLIDING TRANSITIONS
        // Slide-In animation when pushing a page
        pushEnter: Transition {
            XAnimator {
                from: myStack.width
                to: 0
                duration: 300
                easing.type: Easing.OutCubic
            }
        }
        // Slide-Out animation when popping a page
        popExit: Transition {
            XAnimator {
                from: 0
                to: myStack.width
                duration: 300
                easing.type: Easing.OutCubic
            }
        }
    }
}
```
