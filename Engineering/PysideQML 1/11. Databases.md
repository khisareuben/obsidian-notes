## 📝 Step 1: Python Backend with SQLite

We’ll use Python’s built‑in `sqlite3` module to manage the database.



```python
# main.py
import sys
import sqlite3
from PySide6.QtCore import QObject, Slot, Signal, Property
from PySide6.QtGui import QGuiApplication
from PySide6.QtQml import QQmlApplicationEngine

class Backend(QObject):
    dataChanged = Signal()

    def __init__(self):
        super().__init__()
        self.conn = sqlite3.connect("database.db")
        self.cursor = self.conn.cursor()
        self.cursor.execute("CREATE TABLE IF NOT EXISTS items (id INTEGER PRIMARY KEY, name TEXT)")
        self.conn.commit()
        self._items = self.fetch_items()

    def fetch_items(self):
        self.cursor.execute("SELECT name FROM items")
        return [row[0] for row in self.cursor.fetchall()]

    def get_items(self):
        return self._items

    @Slot(str)
    def add_item(self, name):
        self.cursor.execute("INSERT INTO items (name) VALUES (?)", (name,))
        self.conn.commit()
        self._items = self.fetch_items()
        self.dataChanged.emit()

    items = Property("QStringList", fget=get_items, notify=dataChanged)

app = QGuiApplication(sys.argv)
engine = QQmlApplicationEngine()

backend = Backend()
engine.rootContext().setContextProperty("backend", backend)

engine.load("main.qml")
if not engine.rootObjects():
    sys.exit(-1)

sys.exit(app.exec())
```

## 🎨 Step 2: QML UI with ListView



```q
// main.qml
import QtQuick
import QtQuick.Controls

ApplicationWindow {
    visible: true
    width: 400
    height: 300
    title: "Database Example"

    Column {
        anchors.centerIn: parent
        spacing: 10

        ListView {
            id: listView
            width: parent.width * 0.8
            height: 150
            model: backend.items

            delegate: Rectangle {
                width: listView.width
                height: 30
                color: index % 2 === 0 ? "lightgray" : "white"

                Text {
                    text: modelData
                    anchors.centerIn: parent
                }
            }
        }

        TextField {
            id: newItem
            placeholderText: "Add new item"
            width: parent.width * 0.8
        }

        Button {
            text: "Save to DB"
            onClicked: backend.add_item(newItem.text)
        }
    }
}
```

## 🧠 Key Concepts Learned

- **SQLite integration**: Using Python’s `sqlite3` for persistent storage.
    
- **CRUD basics**: Create and Read implemented (`INSERT`, `SELECT`).
    
- **Property binding**: QML updates automatically when Python emits `dataChanged`.
    
- **Persistence**: Data remains even after restarting the app.
