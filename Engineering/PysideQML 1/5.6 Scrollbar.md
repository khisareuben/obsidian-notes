
# 📌 PySide6 + QML ScrollBar Notes

## **Purpose**

- `ScrollBar` provides a visual indicator and control for scrolling content.
    
- Often used with `Flickable`, `ListView`, `GridView`, or `TextArea`.
    
- Can be vertical or horizontal.
    

## **Basic Usage**

qml

```python
import QtQuick
import QtQuick.Controls

Flickable {
    width: 200; height: 200
    contentWidth: 400; contentHeight: 400

    Rectangle {
        width: 400; height: 400
        color: "lightblue"
    }

    ScrollBar.vertical: ScrollBar { }
}
```

- `ScrollBar.vertical` attaches a vertical scrollbar.
    
- `ScrollBar.horizontal` attaches a horizontal scrollbar.
    

## **Properties**

- `orientation` → `Qt.Vertical` or `Qt.Horizontal`.
    
- `policy` → controls visibility:
    
    - `ScrollBar.AlwaysOn`
        
    - `ScrollBar.AlwaysOff`
        
    - `ScrollBar.AsNeeded`
        
- `active` → whether the scrollbar is currently being interacted with.
    
- `position` → current scroll position (0.0–1.0).
    
- `size` → proportion of visible content (0.0–1.0).
    

## **Example: TextArea with ScrollBar**

qml

```python
TextArea {
    width: 200; height: 100
    text: "This is a long text...\nLine 2\nLine 3\nLine 4\nLine 5\nLine 6"

    ScrollBar.vertical: ScrollBar {
        policy: ScrollBar.AsNeeded
    }
}
```

## **Custom Styling**

- ScrollBars can be styled with custom indicators:
    

qml

```python
ScrollBar {
    orientation: Qt.Vertical
    policy: ScrollBar.AlwaysOn

    contentItem: Rectangle {
        implicitWidth: 6
        radius: 3
        color: control.active ? "blue" : "gray"
    }
}
```

## **Best Practices**

- Use `policy: ScrollBar.AsNeeded` for cleaner UI.
    
- Pair with `Flickable`, `ListView`, or `TextArea` for natural scrolling.
    
- Customize `contentItem` for modern UI styles.
    
- Keep scrollbar width minimal to avoid clutter.
