
# Part 6: Menu Bars in PySide6 + QML

Menu bars are essential for desktop‑style applications. In QML, you can create menus (`File`, `Edit`, etc.) and connect them to Python functions.

## 📂 Project Structure

Code

```
pyside6_qml_menubar/
├── main.py
└── main.qml
```

## 📝 Step 1: Python Backend



```python
# main.py
import sys
from PySide6.QtCore import QObject, Slot
from PySide6.QtGui import QGuiApplication
from PySide6.QtQml import QQmlApplicationEngine

class Backend(QObject):
    @Slot()
    def new_file(self):
        print("New File created!")

    @Slot()
    def open_file(self):
        print("Open File triggered!")

    @Slot()
    def exit_app(self):
        print("Exiting application...")
        sys.exit(0)

app = QGuiApplication(sys.argv)
engine = QQmlApplicationEngine()

backend = Backend()
engine.rootContext().setContextProperty("backend", backend)

engine.load("main.qml")
if not engine.rootObjects():
    sys.exit(-1)

sys.exit(app.exec())
```

## 🎨 Step 2: QML Menu Bar



```python
// main.qml
import QtQuick
import QtQuick.Controls

ApplicationWindow {
    visible: true
    width: 500
    height: 300
    title: "Menu Bar Example"

    menuBar: MenuBar {
        Menu {
            title: "File"
            MenuItem {
                text: "New"
                onTriggered: backend.new_file()
            }
            MenuItem {
                text: "Open"
                onTriggered: backend.open_file()
            }
            MenuSeparator {}
            MenuItem {
                text: "Exit"
                onTriggered: backend.exit_app()
            }
        }

        Menu {
            title: "Edit"
            MenuItem { text: "Undo" }
            MenuItem { text: "Redo" }
        }

        Menu {
            title: "Help"
            MenuItem { text: "About" }
        }
    }
}
```

## ▶️ Step 3: Run the App



```zsh
python main.py
```

- You’ll see a window with a **menu bar** at the top.
    
- Clicking **File → New** prints _“New File created!”_ in the terminal.
    
- Clicking **File → Exit** closes the app.
