
# 📌 PySide6 + QML Networking with APIs (`requests`)

## **Purpose**

- Connect your app to external services (REST APIs, JSON endpoints).
    
- Common tasks:
    
    - Fetching data (GET)
        
    - Sending data (POST)
        
    - Updating (PUT/PATCH)
        
    - Deleting (DELETE)
        

## **Python Requests Basics**

- Install: `pip install requests`
    
- Example GET request:
    

```python
import requests

response = requests.get("https://jsonplaceholder.typicode.com/users")
if response.status_code == 200:
    data = response.json()
    print(data)
```

- Example POST request:
    

```python
payload = {"name": "Alice", "email": "alice@example.com"}
response = requests.post("https://jsonplaceholder.typicode.com/users", json=payload)
print(response.json())
```

## **Integrating with PySide6**

- Use a `QObject` class with `Slot`s to expose API calls to QML.
    
- Example:
    

```python
from PySide6.QtCore import QObject, Slot
import requests

class ApiHandler(QObject):
    @Slot()
    def fetchUsers(self):
        response = requests.get("https://jsonplaceholder.typicode.com/users")
        if response.status_code == 200:
            users = response.json()
            print("Fetched users:", users)
```

## **Connecting QML to API**

- Expose `ApiHandler` to QML context.
    
- Call methods from QML buttons.
    

## **Displaying API Data in QML**

- For simplicity, print results to console first.
    
- For UI, bind data to a `ListView` using a `QAbstractListModel` or pass JSON strings.
    

## **Best Practices**

- Always check `status_code` before using response.
    
- Use `try/except` for error handling.
    
- Avoid blocking UI: run requests in a separate thread or async.
    
- Use JSON (`response.json()`) for structured data.
    

# ✅ Complete Example

Here’s a **minimal working project** with one Python file (`main.py`) and one QML file (`main.qml`) that fetches data from a public API.

### **main.py**


```python
import sys
import requests
from PySide6.QtCore import QObject, Slot, QUrl
from PySide6.QtWidgets import QApplication
from PySide6.QtQml import QQmlApplicationEngine

class ApiHandler(QObject):
    @Slot()
    def fetchUsers(self):
        try:
            response = requests.get("https://jsonplaceholder.typicode.com/users")
            if response.status_code == 200:
                users = response.json()
                print("Fetched users:")
                for user in users:
                    print(user["id"], user["name"], user["email"])
            else:
                print("Error:", response.status_code)
        except Exception as e:
            print("Request failed:", e)

    @Slot(str, str)
    def addUser(self, name, email):
        try:
            payload = {"name": name, "email": email}
            response = requests.post("https://jsonplaceholder.typicode.com/users", json=payload)
            print("User added:", response.json())
        except Exception as e:
            print("Request failed:", e)

app = QApplication(sys.argv)
engine = QQmlApplicationEngine()

apiHandler = ApiHandler()
engine.rootContext().setContextProperty("apiHandler", apiHandler)

engine.load(QUrl("main.qml"))

if not engine.rootObjects():
    sys.exit(-1)
sys.exit(app.exec())
```

### **main.qml**


```python
import QtQuick
import QtQuick.Controls

ApplicationWindow {
    visible: true
    width: 400
    height: 300
    title: "API Networking Example"

    Column {
        anchors.centerIn: parent
        spacing: 10

        Button {
            text: "Fetch Users"
            onClicked: apiHandler.fetchUsers()
        }

        TextField {
            id: nameField
            placeholderText: "Enter name"
        }

        TextField {
            id: emailField
            placeholderText: "Enter email"
        }

        Button {
            text: "Add User"
            onClicked: apiHandler.addUser(nameField.text, emailField.text)
        }
    }
}
```

# 🚀 How It Works

1. Run `python main.py`.
    
2. Click **Fetch Users** → prints user list from API in console.
    
3. Enter name + email → click **Add User** → sends POST request and prints response.
