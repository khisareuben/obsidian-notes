
# 📌 PySide6 + QML Database CRUD Notes

## **Purpose**

- CRUD = **Create, Read, Update, Delete**.
    
- In PySide6 + QML, the **UI (QML)** handles user interaction, while the **logic (Python)** manages database operations.
    
- Commonly used with **SQLite** for lightweight local storage.
    

## **Setup**

- Use Python’s `sqlite3` module.
    
- Create a database and table:
    


```python
import sqlite3
conn = sqlite3.connect("app.db")
cursor = conn.cursor()
cursor.execute("CREATE TABLE IF NOT EXISTS users (id INTEGER PRIMARY KEY, name TEXT, email TEXT)")
conn.commit()
```

## **Create (Insert)**


```python
cursor.execute("INSERT INTO users (name, email) VALUES (?, ?)", ("Alice", "alice@example.com"))
conn.commit()
```

## **Read (Select)**


```python
cursor.execute("SELECT * FROM users")
rows = cursor.fetchall()
for row in rows:
    print(row)
```

## **Update**


```python
cursor.execute("UPDATE users SET email=? WHERE id=?", ("newalice@example.com", 1))
conn.commit()
```

## **Delete**


```python
cursor.execute("DELETE FROM users WHERE id=?", (1,))
conn.commit()
```

## **Connecting QML to Python**

- Use `QObject` + `Slot` to expose Python functions to QML.
    
- Example:
    

```python
from PySide6.QtCore import QObject, Slot

class DatabaseHandler(QObject):
    @Slot(str, str)
    def addUser(self, name, email):
        cursor.execute("INSERT INTO users (name, email) VALUES (?, ?)", (name, email))
        conn.commit()
```

## **Displaying Data in QML**

- Use `ListView` with a model populated from Python.
    
- For simplicity, you can print results to console first, then later bind to a QML model.
    

# ✅ Complete Example

Here’s a **minimal working project** with one Python file (`main.py`) and one QML file (`main.qml`).

### **main.py**


```python
import sys
import sqlite3
from PySide6.QtCore import QObject, Slot, QUrl
from PySide6.QtWidgets import QApplication
from PySide6.QtQml import QQmlApplicationEngine

# Database setup
conn = sqlite3.connect("app.db")
cursor = conn.cursor()
cursor.execute("CREATE TABLE IF NOT EXISTS users (id INTEGER PRIMARY KEY, name TEXT, email TEXT)")
conn.commit()

# Database handler exposed to QML
class DatabaseHandler(QObject):
    @Slot(str, str)
    def addUser(self, name, email):
        cursor.execute("INSERT INTO users (name, email) VALUES (?, ?)", (name, email))
        conn.commit()
        print("User added:", name, email)

    @Slot()
    def listUsers(self):
        cursor.execute("SELECT * FROM users")
        rows = cursor.fetchall()
        print("Users in DB:")
        for row in rows:
            print(row)

    @Slot(int, str)
    def updateUser(self, user_id, new_email):
        cursor.execute("UPDATE users SET email=? WHERE id=?", (new_email, user_id))
        conn.commit()
        print("User updated:", user_id, new_email)

    @Slot(int)
    def deleteUser(self, user_id):
        cursor.execute("DELETE FROM users WHERE id=?", (user_id,))
        conn.commit()
        print("User deleted:", user_id)

app = QApplication(sys.argv)
engine = QQmlApplicationEngine()

dbHandler = DatabaseHandler()
engine.rootContext().setContextProperty("dbHandler", dbHandler)

engine.load(QUrl("main.qml"))

if not engine.rootObjects():
    sys.exit(-1)
sys.exit(app.exec())
```

### **main.qml**

qml

```python
import QtQuick
import QtQuick.Controls

ApplicationWindow {
    visible: true
    width: 400
    height: 300
    title: "Database CRUD Example"

    Column {
        anchors.centerIn: parent
        spacing: 10

        TextField {
            id: nameField
            placeholderText: "Enter name"
        }

        TextField {
            id: emailField
            placeholderText: "Enter email"
        }

        Button {
            text: "Add User"
            onClicked: dbHandler.addUser(nameField.text, emailField.text)
        }

        Button {
            text: "List Users"
            onClicked: dbHandler.listUsers()
        }

        Button {
            text: "Update User (id=1)"
            onClicked: dbHandler.updateUser(1, "updated@example.com")
        }

        Button {
            text: "Delete User (id=1)"
            onClicked: dbHandler.deleteUser(1)
        }
    }
}
```

# 🚀 How It Works

1. Run `python main.py`.
    
2. The QML window opens with text fields and buttons.
    
3. Enter a name + email → click **Add User**.
    
4. Click **List Users** → prints all users in console.
    
5. Click **Update User** → updates email for user with `id=1`.
    
6. Click **Delete User** → deletes user with `id=1`.
