
## Step 1: Making the Blueprint (`Theme.qml`)

Inside `Theme.qml`, we create a variable named `isDark` and set it to `true`.

We then define our colors using a **conditional statement** (like an `if / else` shortcut): `isDark ? "DarkColor" : "LightColor"`

QML

```JavaScript
// Theme.qml
QtObject {
    // 1. This is our master switch. It can only be true or false.
    property bool isDark: true

    // 2. We define our background color based on that switch:
    // "Is isDark true? If yes, use #121212 (Dark). If no, use #F5F5F5 (Light)."
    readonly property color background: isDark ? "#121212" : "#F5F5F5"
    readonly property color text:       isDark ? "#FFFFFF" : "#1A1A1A"
}
```

## Step 2: Registering the Theme (`qmldir`)

By default, QML treats files as separate pages. To make `Theme.qml` act like a global "Stylesheet" that every page can see, we write a one-line text file named `qmldir`:

Plaintext

```
singleton Theme 1.0 Theme.qml
```

_This simply tells QML: "Whenever I type `Theme` in any file, look inside `Theme.qml`."_

## Step 3: Connecting Your UI to the Theme

In your main application window, you don't type hardcoded colors like `"#121212"`. Instead, you **bind** your properties to `Theme.background` and `Theme.text`.

QML

```JavaScript
// main.qml
ApplicationWindow {
    visible: true
    
    // The window color is now bound to whatever Theme.background currently is
    color: Theme.background 

    Text {
        text: "Hello World"
        // The text color is bound to whatever Theme.text currently is
        color: Theme.text
    }
}
```

## Step 4: Triggering the Change (The "Click" Event)

Right now, `isDark` is `true`. So:

1. `Theme.background` resolves to `"#121212"` (Dark).
    
2. Your window turns dark gray.
    

If we add a button to change `isDark` to `false`, a chain reaction occurs:

QML

```JavaScript
Button {
    text: "Toggle Light/Dark Mode"
    
    onClicked: {
        // We flip the true/false switch!
        Theme.isDark = !Theme.isDark 
    }
}
```

### The Chain Reaction:

1. You click the button.
    
2. `Theme.isDark` changes from `true` to `false`.
    
3. QML notices `isDark` changed. It immediately recalculates `background` and `text` inside `Theme.qml`.
    
4. `Theme.background` now evaluates to `"#F5F5F5"` (Light).
    
5. Your `ApplicationWindow` notices `Theme.background` changed. It immediately repaints itself light gray.
    
6. Your text turns dark.
    

You don't have to write any code to "refresh" the screen—QML handles the entire update automatically the instant the switch is flipped.
