
# 📌 PySide6 + QML MouseArea Notes

## **Purpose**

- `MouseArea` is an invisible interactive area that detects mouse/touch input.
    
- Commonly used for clicks, hovering, dragging, and gestures.
    
- Often placed inside visual elements (`Rectangle`, `Image`, etc.) to make them interactive.
    

## **Basic Usage**

qml

```python
Rectangle {
    width: 200; height: 200; color: "lightgray"

    MouseArea {
        anchors.fill: parent
        onClicked: console.log("Rectangle clicked!")
    }
}
```

- `anchors.fill: parent` makes the MouseArea cover the entire parent.
    
- `onClicked` handles mouse click events.
    

## **Common Signals**

- `onClicked` → Triggered when the area is clicked.
    
- `onPressed` → Triggered when mouse button is pressed.
    
- `onReleased` → Triggered when mouse button is released.
    
- `onDoubleClicked` → Triggered on double-click.
    
- `onPositionChanged` → Triggered when mouse moves inside the area.
    
- `onEntered` / `onExited` → Triggered when mouse enters or leaves the area.
    

## **Properties**

- `hoverEnabled: true` → Detects hover events.
    
- `acceptedButtons: Qt.LeftButton | Qt.RightButton` → Specify which buttons are accepted.
    
- `cursorShape: Qt.PointingHandCursor` → Change cursor when hovering.
    
- `drag.target` → Enables dragging of an item.
    

## **Example: Button with MouseArea**

qml

```python
Rectangle {
    width: 100; height: 40; color: "blue"

    MouseArea {
        anchors.fill: parent
        onClicked: {
            console.log("Button clicked!")
            parent.color = "green"
        }
    }
}
```

## **Example: Dragging**

qml

```python
Rectangle {
    width: 50; height: 50; color: "red"

    MouseArea {
        anchors.fill: parent
        drag.target: parent
    }
}
```

- Allows the rectangle to be dragged around.
    

## **Best Practices**

- Always use `anchors.fill: parent` for clickable areas.
    
- Use `hoverEnabled` for hover effects.
    
- Combine with `Rectangle`, `Image`, or `Text` to make UI elements interactive.
    
- For complex gestures, consider `MultiPointTouchArea`.
