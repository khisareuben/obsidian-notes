
# 📌 PySide6 + QML Resource Files for Images

## **Purpose**

- Bundle images, icons, and other assets directly into the application binary.
    
- Prevents missing file errors when distributing your app.
    
- Allows referencing images with `qrc:/` paths instead of relative file paths.
    

## **Steps to Create a Resource File**

1. **Create a** `.qrc` **file** Example: `resources.qrc`
    
    
    ```xml
    <RCC>
      <qresource prefix="/">
        <file>icons/logo.png</file>
        <file>icons/background.jpg</file>
      </qresource>
    </RCC>
    ```
    
2. **Compile the** `.qrc` **file** Use the PySide6 tool:
    
    
    
    ```bash
    pyside6-rcc resources.qrc -o resources_rc.py
    ```
    
    - This generates a Python file (`resources_rc.py`) that embeds the assets.
        
3. **Import the compiled resource file** In your Python entry script:
    
    
    
    ```python
    import resources_rc
    ```
    
4. **Reference images in QML** Use the `qrc:/` prefix:
    
    qml
    
    ```python
    Image {
        source: "qrc:/icons/logo.png"
        width: 64
        height: 64
    }
    ```
    

## **Prefix Usage**

- `prefix="/"` → Images accessed as `qrc:/icons/logo.png`
    
- `prefix="/assets"` → Images accessed as `qrc:/assets/logo.png`
    
- Helps organize resources into logical namespaces.
    

## **Best Practices**

- Keep all images in a dedicated `icons/` or `assets/` folder.
    
- Use **SVGs** for scalable icons.
    
- Group related resources under different prefixes.
    
- Always compile `.qrc` into Python before running the app.
    

## **Example Project Structure**

Code

```
project/
│── main.py
│── resources.qrc
│── resources_rc.py
│── qml/
│    └── main.qml
│── icons/
     ├── logo.png
     └── background.jpg
```

## **Advantages**

- No need to ship loose image files.
    
- Works across platforms (Linux, Windows, macOS).
    
- Ensures consistent paths in QML.
