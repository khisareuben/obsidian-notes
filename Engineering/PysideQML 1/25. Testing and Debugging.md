## 📝 Step 1: Unit Testing with Pytest

Let’s say your backend has a simple function:


```python
# backend/logic.py
def calculate_bill(amount, fine=0):
    return amount + fine
```

You can test it with `pytest`:



```python
# backend/test_logic.py
import pytest
from logic import calculate_bill

def test_calculate_bill_no_fine():
    assert calculate_bill(100) == 100

def test_calculate_bill_with_fine():
    assert calculate_bill(100, 20) == 120
```

Run tests:



```zsh
pytest backend/test_logic.py
```

📌 This ensures your business logic works correctly before connecting it to QML.

## 🎨 Step 2: Debugging QML

QML has a built‑in `console.log()` for debugging:


```q
Button {
    text: "Test Button"
    onClicked: {
        console.log("Button clicked, text:", text)
    }
}
```

📌 Output appears in the terminal running your app.

## 📝 Step 3: Error Handling in QML

Catch errors gracefully:



```q
try {
    var result = riskyFunction()
    console.log("Result:", result)
} catch (err) {
    console.log("Error occurred:", err)
}
```

📌 This prevents crashes when QML scripts fail.

## 📝 Step 4: Profiling Performance

Use Python’s `cProfile` to measure performance:



```python
import cProfile
import backend.logic

cProfile.run("backend.logic.calculate_bill(100, 20)")
```

📌 This shows how long functions take, helping you optimize slow code.

## 📝 Step 5: Logging for Debugging

Combine with **Part 23 (Logging)**:



```python
import logging
logging.basicConfig(level=logging.DEBUG)

logging.debug("Debugging info")
logging.info("General info")
logging.error("Error occurred")
```

📌 Logs help track issues across sessions.
