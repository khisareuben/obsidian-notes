## 📝 Step 1: Python Backend

We’ll expose a Python slot that updates a label in QML.

python

```
# main.py
import sys
from PySide6.QtCore import QObject, Slot, Signal
from PySide6.QtGui import QGuiApplication
from PySide6.QtQml import QQmlApplicationEngine

class Backend(QObject):
    # Define a signal that sends text to QML
    textChanged = Signal(str)

    @Slot()
    def update_text(self):
        self.textChanged.emit("Updated from Python!")

app = QGuiApplication(sys.argv)
engine = QQmlApplicationEngine()

backend = Backend()
engine.rootContext().setContextProperty("backend", backend)

engine.load("main.qml")
if not engine.rootObjects():
    sys.exit(-1)

sys.exit(app.exec())
```

## 🎨 Step 2: QML Label

We’ll create a `Label` that listens for updates from Python.

qml

```
// main.qml
import QtQuick
import QtQuick.Controls

ApplicationWindow {
    visible: true
    width: 400
    height: 200
    title: "Labels Example"

    Column {
        anchors.centerIn: parent
        spacing: 10

        Label {
            id: dynamicLabel
            text: "Initial Text"
            font.pixelSize: 20
        }

        Button {
            text: "Update Label"
            onClicked: backend.update_text()
        }
    }

    Connections {
        target: backend
        onTextChanged: dynamicLabel.text = text
    }
}
```

## ▶️ Step 3: Run the App

- Start with **“Initial Text”** displayed.
    
- Click **Update Label** → the text changes to **“Updated from Python!”**.
    

## 🎨 Step 4: Styling Text

You can style text with properties:

qml

```
Label {
    text: "Styled Label"
    font.pixelSize: 24
    color: "blue"
    horizontalAlignment: Text.AlignHCenter
}
```

## 🧠 Key Concepts Learned

- **Label/Text**: Used to display static or dynamic text.
    
- **Signals**: Python emits signals to notify QML of changes.
    
- **Connections**: QML listens to signals and updates UI.
    
- **Styling**: Font size, color, alignment.
