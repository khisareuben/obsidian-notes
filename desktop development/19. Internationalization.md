
**Part 19: Internationalization (i18n) in PySide6 + QML**. This lesson will show you how to make your apps multilingual — so users can switch languages dynamically without needing separate builds. This is especially useful if you want your apps to be usable in both English and Kiswahili, or any other language.

# Part 19: Internationalization (i18n)

## 📂 Project Structure

Code

```
pyside6_qml_i18n/
├── main.py
├── main.qml
├── translations/
│   ├── app_en.ts
│   ├── app_sw.ts
│   └── app_en.qm
│   └── app_sw.qm
```

## 📝 Step 1: Mark Texts for Translation in QML

Use `qsTr()` around any text you want translated.

qml

```
// main.qml
import QtQuick
import QtQuick.Controls

ApplicationWindow {
    visible: true
    width: 400
    height: 300
    title: qsTr("Internationalization Example")

    Column {
        anchors.centerIn: parent
        spacing: 10

        Label { text: qsTr("Hello World") }
        Button { text: qsTr("Click Me") }
    }
}
```

📌 `qsTr()` tells Qt that this string should be translated.

## 📝 Step 2: Extract Translations

Run the Qt tool `lupdate` to generate `.ts` files (translation source files).

zsh

```
lupdate main.qml -ts translations/app_en.ts translations/app_sw.ts
```

This creates files with all translatable strings.

## 📝 Step 3: Edit Translation Files

Open `app_sw.ts` and translate:

xml

```
<message>
    <source>Hello World</source>
    <translation>Habari Dunia</translation>
</message>
<message>
    <source>Click Me</source>
    <translation>Bofya Mimi</translation>
</message>
```

## 📝 Step 4: Compile Translations

Convert `.ts` files into `.qm` (binary format) using `lrelease`.

zsh

```
lrelease translations/app_en.ts -qm translations/app_en.qm
lrelease translations/app_sw.ts -qm translations/app_sw.qm
```

## 📝 Step 5: Load Translator in Python

Switch languages dynamically by loading `.qm` files.

python

```
# main.py
import sys
from PySide6.QtCore import QTranslator, QLocale, QLibraryInfo
from PySide6.QtGui import QGuiApplication
from PySide6.QtQml import QQmlApplicationEngine

app = QGuiApplication(sys.argv)

translator = QTranslator()
translator.load("translations/app_sw.qm")
app.installTranslator(translator)

engine = QQmlApplicationEngine()
engine.load("main.qml")

if not engine.rootObjects():
    sys.exit(-1)

sys.exit(app.exec())
```

📌 This loads the Kiswahili translation. Change to `app_en.qm` for English.

## 🎨 Step 6: Dynamic Language Switching

You can expose a slot to QML to switch languages at runtime.

python

```
class LanguageManager(QObject):
    def __init__(self, app, engine):
        super().__init__()
        self.app = app
        self.engine = engine
        self.translator = QTranslator()

    @Slot(str)
    def switch_language(self, lang):
        if lang == "sw":
            self.translator.load("translations/app_sw.qm")
        else:
            self.translator.load("translations/app_en.qm")
        self.app.installTranslator(self.translator)
        self.engine.retranslate()
```

And in QML:

qml

```
Button {
    text: qsTr("Switch to Kiswahili")
    onClicked: languageManager.switch_language("sw")
}
```

## 🧠 Key Concepts Learned

- **qsTr()**: Marks strings for translation.
    
- **lupdate/lrelease**: Extract and compile translations.
    
- **.ts/.qm files**: Source vs compiled translations.
    
- **QTranslator**: Loads translations in Python.
    
- **Dynamic switching**: Change language at runtime.
