## 📝 Step 1: Hashing Passwords (Never Store Plain Text)

Use Python’s `hashlib` to hash passwords before saving them (e.g., in SQLite).



```python
# main.py
import sys, hashlib
from PySide6.QtCore import QObject, Slot, Signal
from PySide6.QtGui import QGuiApplication
from PySide6.QtQml import QQmlApplicationEngine

class SecurityManager(QObject):
    loginResult = Signal(str)

    def __init__(self):
        super().__init__()
        # Example: stored hashed password (sha256 of "mypassword")
        self.stored_hash = hashlib.sha256("mypassword".encode()).hexdigest()

    @Slot(str)
    def check_password(self, password):
        # Hash the input
        entered_hash = hashlib.sha256(password.encode()).hexdigest()
        if entered_hash == self.stored_hash:
            self.loginResult.emit("Access Granted")
        else:
            self.loginResult.emit("Access Denied")

app = QGuiApplication(sys.argv)
engine = QQmlApplicationEngine()

security_manager = SecurityManager()
engine.rootContext().setContextProperty("securityManager", security_manager)

engine.load("main.qml")
if not engine.rootObjects():
    sys.exit(-1)

sys.exit(app.exec())
```

## 📝 Step 3: Encrypting Sensitive Data

For more than simple passwords, use the `cryptography` library to encrypt/decrypt files or tokens.



```python
from cryptography.fernet import Fernet

# Generate a key (store securely!)
key = Fernet.generate_key()
cipher = Fernet(key)

# Encrypt data
token = cipher.encrypt(b"Secret message")

# Decrypt data
plain = cipher.decrypt(token)
print(plain.decode())  # "Secret message"
```

📌 Store the key securely (not hardcoded in code). For rural/offline setups, you can keep it in a config file or environment variable.

## 📝 Step 4: Secure File Handling

When saving sensitive files:

- Encrypt before writing.
    
- Decrypt only when needed.
    



```python
def save_secure_file(path, content, cipher):
    with open(path, "wb") as f:
        f.write(cipher.encrypt(content.encode()))

def load_secure_file(path, cipher):
    with open(path, "rb") as f:
        data = f.read()
        return cipher.decrypt(data).decode()
```

## 🧠 Key Concepts Learned

- **Hashing**: One‑way protection for passwords (never store plain text).
    
- **Encryption**: Protect sensitive data with reversible keys.
    
- **Secure storage**: Keep keys/configs separate from code.
    
- **QML integration**: Password fields with `echoMode` hide input.
    

## ⚡ Best Practices

- Always hash passwords before saving.
    
- Use encryption for files or tokens.
    
- Never hardcode secrets in code — use config files or environment variables.
    
- Combine with **Part 20 (Settings)** to store preferences securely.
