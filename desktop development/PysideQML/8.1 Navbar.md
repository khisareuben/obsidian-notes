
# 📌 PySide6 + QML Navigation Bar (Navbar) Notes

## **Purpose**

- A navigation bar provides quick access to different sections of an application.
    
- Commonly implemented as a **horizontal row** of buttons or icons.
    
- Can be styled to resemble modern app navbars (top or bottom).
    

## **Basic Navbar with Row**

qml

```python
import QtQuick
import QtQuick.Controls

Rectangle {
    width: 400; height: 50; color: "lightgray"

    Row {
        anchors.centerIn: parent
        spacing: 20

        Button { text: "Home" }
        Button { text: "Settings" }
        Button { text: "Profile" }
    }
}
```

- Simple horizontal navbar with text buttons.
    

## **Navbar with Icons**

qml

```python
Row {
    spacing: 30
    anchors.centerIn: parent

    Image {
        source: "qrc:/icons/home.png"
        MouseArea {
            anchors.fill: parent
            onClicked: console.log("Home clicked")
        }
    }

    Image {
        source: "qrc:/icons/settings.png"
        MouseArea {
            anchors.fill: parent
            onClicked: console.log("Settings clicked")
        }
    }
}
```

- Uses icons with `MouseArea` for interaction.
    

## **Bottom Navbar**

qml

```python
Rectangle {
    width: parent.width; height: 60; color: "#333"

    Row {
        anchors.centerIn: parent
        spacing: 40

        Button { text: "Dashboard" }
        Button { text: "Messages" }
        Button { text: "Profile" }
    }
}
```

- Placed at the bottom of the app window.
    

## **StackView Integration**

- Navbars often control navigation between pages using `StackView`.
    

qml

```python
ApplicationWindow {
    visible: true; width: 400; height: 300

    StackView {
        id: stack
        anchors.fill: parent
        initialItem: homePage
    }

    Rectangle {
        height: 50; width: parent.width; color: "lightgray"
        anchors.bottom: parent.bottom

        Row {
            anchors.centerIn: parent; spacing: 20

            Button { text: "Home"; onClicked: stack.push(homePage) }
            Button { text: "Settings"; onClicked: stack.push(settingsPage) }
        }
    }

    Component { id: homePage; Rectangle { color: "white" } }
    Component { id: settingsPage; Rectangle { color: "lightblue" } }
}
```

- Clicking navbar buttons switches between pages.
    

## **Best Practices**

- Use **icons + text** for clarity.
    
- Keep spacing consistent for a clean look.
    
- Place navbar at **top** for desktop apps, **bottom** for mobile apps.
    
- Combine with `StackView` or `Loader` for page navigation.
    
- Use `MouseArea` or `Button` depending on whether you want custom styling or built-in controls.
