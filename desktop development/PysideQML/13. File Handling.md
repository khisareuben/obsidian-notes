## 📝 Step 1: Python Backend — Read & Write Files



```python
# main.py
import sys
from PySide6.QtCore import QObject, Slot, Signal
from PySide6.QtGui import QGuiApplication
from PySide6.QtQml import QQmlApplicationEngine

class Backend(QObject):
    fileContentChanged = Signal(str)

    @Slot(str)
    def open_file(self, path):
        try:
            with open(path, "r", encoding="utf-8") as f:
                content = f.read()
                self.fileContentChanged.emit(content)
        except Exception as e:
            print("Error opening file:", e)

    @Slot(str, str)
    def save_file(self, path, content):
        try:
            with open(path, "w", encoding="utf-8") as f:
                f.write(content)
            print("File saved:", path)
        except Exception as e:
            print("Error saving file:", e)

app = QGuiApplication(sys.argv)
engine = QQmlApplicationEngine()

backend = Backend()
engine.rootContext().setContextProperty("backend", backend)

engine.load("main.qml")
if not engine.rootObjects():
    sys.exit(-1)

sys.exit(app.exec())
```

        id: openDialog

    }

        id: saveDialog
        title: "Save File As"
        selectExisting: false
        nameFilters: ["Text files (*.txt)", "All files (*)"]
        onAccepted: backend.save_file(saveDialog.file, editor.text)
    }

    Connections {
        target: backend

    }
}

# 📌 PySide6 + QML File Handling Notes

## **Purpose**

- Manage files within QML applications.
    
- Common tasks: reading, writing, uploading, and selecting files.
    
- Often combined with Python backend (PySide6) for actual file operations.
    

## **FileDialog**

- Provides a native file picker dialog.
    
- Example:
    
    qml
    
    ```python
    import QtQuick
    import QtQuick.Controls
    import QtQuick.Dialogs
    
    FileDialog {
        id: fileDialog
        title: "Select a file"
        nameFilters: ["Text files (*.txt)", "All files (*)"]
        onAccepted: {
            console.log("Selected file:", fileDialog.file)
        }
    }
    
    Button {
        text: "Open File"
        onClicked: fileDialog.open()
    }
    ```
    
- `fileDialog.file` → returns the selected file path.
    

## **Uploading a File**

- QML itself doesn’t upload files; you pass the selected path to Python.
    
- Example workflow:
    
    1. Use `FileDialog` to select a file.
        
    2. Send the file path to Python via `QObject` or `Slot`.
        
    3. Handle upload logic (e.g., send to server, copy locally) in Python.
        

python

```python
from PySide6.QtCore import QObject, Slot

class FileHandler(QObject):
    @Slot(str)
    def uploadFile(self, path):
        print("Uploading file:", path)
        # Example: open and read
        with open(path, "r") as f:
            data = f.read()
        # Upload logic here
```

QML side:

qml

```python
FileDialog {
    id: fileDialog
    onAccepted: fileHandler.uploadFile(fileDialog.file)
}
```

## **Reading/Writing Files in Python**

- Standard Python file handling:
    
    python
    
    ```python
    with open("data.txt", "w") as f:
        f.write("Hello QML")
    ```
    
- Reading:
    
    python
    
    ```python
    with open("data.txt", "r") as f:
        content = f.read()
        print(content)
    ```
    

## **Best Practices**

- Use `FileDialog` for user-friendly file selection.
    
- Handle actual file operations in Python, not QML.
    
- Validate file paths before reading/writing.
    
- For uploads, consider using `requests` or `aiohttp` in Python.
