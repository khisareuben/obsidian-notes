## 📝 Step 1: Python Backend with QSettings

Qt provides `QSettings` for storing preferences in a platform‑native way:

- On Linux → `~/.config/YourApp/YourApp.conf`
    
- On Windows → Registry
    
- On macOS → `~/Library/Preferences`
    

python

```
# main.py
import sys
from PySide6.QtCore import QSettings, QObject, Slot, Signal
from PySide6.QtGui import QGuiApplication
from PySide6.QtQml import QQmlApplicationEngine

class SettingsManager(QObject):
    themeChanged = Signal(str)

    def __init__(self):
        super().__init__()
        self.settings = QSettings("MyCompany", "MyApp")
        self._theme = self.settings.value("theme", "light")  # default: light

    def get_theme(self):
        return self._theme

    @Slot(str)
    def set_theme(self, theme):
        self._theme = theme
        self.settings.setValue("theme", theme)
        self.themeChanged.emit(theme)

app = QGuiApplication(sys.argv)
engine = QQmlApplicationEngine()

settings_manager = SettingsManager()
engine.rootContext().setContextProperty("settingsManager", settings_manager)

engine.load("main.qml")
if not engine.rootObjects():
    sys.exit(-1)

sys.exit(app.exec())
```

## 🎨 Step 2: QML UI with Theme Toggle

We’ll let the user switch between light and dark themes, and remember their choice.

qml

```
// main.qml
import QtQuick
import QtQuick.Controls

ApplicationWindow {
    visible: true
    width: 400
    height: 300
    title: "Settings Example"

    Column {
        anchors.centerIn: parent
        spacing: 15

        Label {
            text: "Current Theme: " + settingsManager.get_theme()
        }

        Button {
            text: "Switch to Dark"
            onClicked: settingsManager.set_theme("dark")
        }

        Button {
            text: "Switch to Light"
            onClicked: settingsManager.set_theme("light")
        }
    }

    Connections {
        target: settingsManager
        onThemeChanged: console.log("Theme changed to:", theme)
    }
}
```

## 🧠 Key Concepts Learned

- **QSettings**: Built‑in storage for preferences.
    
- **Persistence**: Values survive across sessions.
    
- **Slots**: Save settings when user changes them.
    
- **Signals**: Notify QML when settings change.
