
# 📌 PySide6 + QML Shapes Notes

## **Purpose**

- `Shape` provides a way to draw vector graphics directly in QML.
    
- Useful for custom UI elements, icons, and scalable graphics.
    
- Introduced in **Qt Quick Shapes** module.
    

## **Basic Usage**

qml

```python
import QtQuick
import QtQuick.Shapes

Shape {
    width: 200; height: 200

    ShapePath {
        strokeWidth: 2
        strokeColor: "black"
        fillColor: "lightblue"

        startX: 20; startY: 20
        PathLine { x: 180; y: 20 }
        PathLine { x: 180; y: 180 }
        PathLine { x: 20; y: 180 }
        PathLine { x: 20; y: 20 }
    }
}
```

- Draws a rectangle using path lines.
    

## **ShapePath**

- Defines the actual drawing instructions.
    
- Properties:
    
    - `strokeColor`, `strokeWidth`
        
    - `fillColor`
        
    - `fillGradient` (for gradients)
        
- Path elements:
    
    - `PathLine` → straight line
        
    - `PathArc` → arc
        
    - `PathCubic` → cubic Bezier curve
        
    - `PathQuad` → quadratic Bezier curve
        

## **Gradients in Shapes**

- Shapes can use gradients for fills:
    
    qml
    
    ```python
    ShapePath {
        strokeWidth: 0
        fillGradient: RadialGradient {
            center: Qt.point(100, 100)
            radius: 100
            GradientStop { position: 0.0; color: "yellow" }
            GradientStop { position: 1.0; color: "green" }
        }
    }
    ```
    

## **Examples**

- **Circle:**
    
    qml
    
    ```python
    ShapePath {
        strokeColor: "red"
        fillColor: "pink"
        PathArc {
            x: 100; y: 0
            radiusX: 50; radiusY: 50
            useLargeArc: true
        }
    }
    ```
    
- **Triangle:**
    
    qml
    
    ```python
    ShapePath {
        strokeColor: "black"
        fillColor: "orange"
        startX: 50; startY: 0
        PathLine { x: 100; y: 100 }
        PathLine { x: 0; y: 100 }
        PathLine { x: 50; y: 0 }
    }
    ```
    

## **Best Practices**

- Use `Shape` for scalable vector graphics instead of raster images.
    
- Keep path definitions simple for performance.
    
- Combine with gradients for polished UI.
    
- Prefer `Shape` over `Canvas` for declarative vector drawing.
