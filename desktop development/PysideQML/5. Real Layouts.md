`import QtQuick.Layouts`
## 🔑 Common Features Across Layouts

All layout types share these **attached properties** (you set them on child items inside the layout):

- **Layout.fillWidth** / **Layout.fillHeight**
    
    - Boolean. If `true`, the item expands to fill available width/height.
        
- **Layout.minimumWidth** / **Layout.minimumHeight**
    
    - Smallest size the item can shrink to.
        
- **Layout.preferredWidth** / **Layout.preferredHeight**
    
    - The “ideal” size the layout tries to give the item.
        
- **Layout.maximumWidth** / **Layout.maximumHeight**
    
    - Largest size the item can grow to.
        
- **Layout.alignment**
    
    - Aligns the item within its cell (e.g., `Qt.AlignLeft`, `Qt.AlignRight`, `Qt.AlignHCenter`, `Qt.AlignVCenter`).
        
- **Layout.margins**
    
    - Sets spacing around the item (top, bottom, left, right).
        
- **Layout.row** / **Layout.column**
    
    - Used in **GridLayout** to place items in specific cells.
        
- **Layout.rowSpan** / **Layout.columnSpan**
    
    - Used in **GridLayout** to make items span multiple rows/columns.
        

## 📐 RowLayout

- **Orientation**: Horizontal.
    
- **Special features**:
    
    - Children can stretch horizontally (`Layout.fillWidth`).
        
    - Vertical alignment via `Layout.alignment`.
        
- **Example**:
    

qml

```JavaScript
RowLayout {
    spacing: 10
    Rectangle { Layout.fillWidth: true; Layout.preferredWidth: 100; height: 50; color: "red" }
    Rectangle { width: 50; height: 50; color: "blue"; Layout.alignment: Qt.AlignVCenter }
}
```

## 📐 ColumnLayout

- **Orientation**: Vertical.
    
- **Special features**:
    
    - Children can stretch vertically (`Layout.fillHeight`).
        
    - Horizontal alignment via `Layout.alignment`.
        
- **Example**:
    

qml

```JavaScript
ColumnLayout {
    spacing: 10
    Rectangle { Layout.fillHeight: true; Layout.preferredHeight: 80; width: 100; color: "green" }
    Rectangle { width: 100; height: 50; color: "yellow"; Layout.alignment: Qt.AlignHCenter }
}
```

## 📐 GridLayout

- **Orientation**: Grid (rows × columns).
    
- **Special features**:
    
    - Place items with `Layout.row` and `Layout.column`.
        
    - Span multiple cells with `Layout.rowSpan` and `Layout.columnSpan`.
        
- **Example**:
    

qml

```JavaScript
GridLayout {
    columns: 2
    Rectangle { Layout.row: 0; Layout.column: 0; color: "orange"; width: 50; height: 50 }
    Rectangle { Layout.row: 0; Layout.column: 1; color: "purple"; width: 50; height: 50 }
    Rectangle { Layout.row: 1; Layout.column: 0; Layout.columnSpan: 2; color: "cyan"; height: 30 }
}
```

## 📐 StackLayout

- **Orientation**: Stacks items on top of each other.
    
- **Special features**:
    
    - Only one child visible at a time (`currentIndex`).
        
    - Useful for tab views or wizards.
        
- **Example**:
    

qml

```JavaScript
StackLayout {
    currentIndex: 0
    Rectangle { color: "pink"; width: 100; height: 100 }
    Rectangle { color: "lightblue"; width: 100; height: 100 }
}
```

## 📐 FlexboxLayout

- **Orientation**: Flexible, CSS‑like.
    
- **Special features**:
    
    - Supports wrapping (`flexWrap`).
        
    - Align items with `justifyContent`, `alignItems`.
        
    - Very powerful for responsive design.
        
- **Example**:
    

qml

```JavaScript
FlexboxLayout {
    flexWrap: FlexboxLayout.Wrap
    Rectangle { Layout.preferredWidth: 100; Layout.preferredHeight: 50; color: "brown" }
    Rectangle { Layout.preferredWidth: 100; Layout.preferredHeight: 50; color: "gray" }
}
```

## ⚖️ Summary Table

|**Layout**|**Orientation**|**Unique Features**|**Best Use Case**|
|---|---|---|---|
|**RowLayout**|Horizontal|FillWidth, vertical alignment|Toolbars, button rows|
|**ColumnLayout**|Vertical|FillHeight, horizontal alignment|Forms, stacked controls|
|**GridLayout**|Grid|Row/column placement, spans|Dashboards, tiled UIs|
|**StackLayout**|Overlapping|currentIndex switching|Tab views, multi‑page|
|**FlexboxLayout**|Flexible|Wrapping, justifyContent, alignItems|Responsive, adaptive layouts|

💡 **Best practice tip**: Always use `Layout.*` properties instead of anchors inside layouts — mixing them causes conflicts. Layouts are designed to manage child sizes and positions automatically.
