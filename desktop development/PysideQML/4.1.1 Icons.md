
**To use font icons in PySide6 + QML, the most practical approach is to integrate an icon library like** _**FeatherIcons**_ **via the** `PySide6-FeatherIcons-QML` **package. This lets you display scalable vector icons directly in QML with customizable size, color, and effects.**

## ⚙️ Setup in Python

1. **Install the library**
    
    
    ```bash
    pip install PySide6-FeatherIcons-QML
    ```
    
2. **Register FeatherIcons in your app**
    
    
    
    ```python
    from PySide6.QtQml import QQmlApplicationEngine
    import FeatherIconsQML
    
    engine = QQmlApplicationEngine()
    FeatherIconsQML.register(engine)
    ```
    
    This makes the `FeatherIcons` module available in QML.
    

## 📖 Using Icons in QML

qml

```JavaScript
import QtQuick
import FeatherIcons

Rectangle {
    width: 200; height: 200; color: "lightgray"

    FeatherIcon {
        icon: "activity"
        iconSize: 48
        color: "blue"
        strokeWidth: 1.5
    }
}
```

### Key Properties

- **icon**: Name of the Feather icon (e.g., `"plus"`, `"activity"`).
    
- **iconSize**: Default is 24, can be scaled up.
    
- **strokeWidth**: Line thickness (0.5–3.0).
    
- **color**: Any valid QML color string.
    
- **shadowEnabled** & blur options: Add visual effects.
    

## 🎛️ Icons in Qt Quick Controls

You can use icons inside buttons, menus, and delegates:

qml

```JavaScript
import QtQuick.Controls
import FeatherIcons

Button {
    text: "Add"
    icon.source: FeatherIconsVault.getSource("plus")
    icon.color: "green"
}
```

- `FeatherIconsVault.getSource("iconName")` returns the icon’s source URL for use in controls.
