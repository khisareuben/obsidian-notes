
# 📌 PySide6 + QML Shadows Notes

## **Purpose**

- Shadows add depth and realism to UI elements.
    
- Commonly used for cards, buttons, and floating panels.
    
- Implemented via **DropShadow** or **InnerShadow** from `QtGraphicalEffects`.
    

## **DropShadow**

- Creates a shadow behind an item.
    
- Example:
    
    qml
    
    ```python
    import QtQuick
    import QtGraphicalEffects
    
    Rectangle {
        width: 200; height: 100; color: "white"
    
        DropShadow {
            anchors.fill: parent
            source: parent
            horizontalOffset: 5
            verticalOffset: 5
            radius: 10
            color: "#80000000"   // semi-transparent black
        }
    }
    ```
    
- Properties:
    
    - `source` → the item casting the shadow.
        
    - `horizontalOffset`, `verticalOffset` → shadow position.
        
    - `radius` → blur radius.
        
    - `color` → shadow color.
        

## **InnerShadow**

- Creates a shadow inside the edges of an item.
    
- Example:
    
    qml
    
    ```python
    Rectangle {
        width: 200; height: 100; color: "lightgray"
    
        InnerShadow {
            anchors.fill: parent
            source: parent
            radius: 8
            color: "black"
        }
    }
    ```
    
- Useful for embossed or inset effects.
    

## **Rectangular Shadow Example**

qml

```python
Rectangle {
    width: 150; height: 80; color: "white"; radius: 8

    DropShadow {
        anchors.fill: parent
        source: parent
        horizontalOffset: 4
        verticalOffset: 4
        radius: 12
        color: "#40000000"
    }
}
```

- Creates a card-like rectangle with a soft shadow.
    

## **Performance Notes**

- Shadows can be expensive if overused.
    
- Keep `radius` small for better performance.
    
- Use shadows sparingly in lists or repeated elements.
    

## **Best Practices**

- Use **DropShadow** for floating elements (cards, dialogs).
    
- Use **InnerShadow** for pressed/inset effects.
    
- Keep shadow colors semi-transparent for natural look.
    
- Combine with rounded corners (`radius`) for modern UI.
