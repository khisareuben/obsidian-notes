## 📝 Step 1: Python Backend

We’ll expose a Python class with a slot (function) that QML can call when the button is clicked.

In **PySide6** with QML, the `@Slot()` decorator is required for methods you want to call from QML code. Without it, QML won't recognize your Python method as callable, and you’ll get a `TypeError` like: _"Property 'log' of object Logger(...) is not a function"_

```python
# main.py
import sys
from PySide6.QtCore import QObject, Slot
from PySide6.QtGui import QGuiApplication
from PySide6.QtQml import QQmlApplicationEngine

class Backend(QObject):
    @Slot()
    def say_hello(self):
        print("Hello from Python!")

app = QGuiApplication(sys.argv)
engine = QQmlApplicationEngine()

backend = Backend()
# Expose backend to QML as a global object
engine.rootContext().setContextProperty("backend", backend)

engine.load("main.qml")
if not engine.rootObjects():
    sys.exit(-1)

sys.exit(app.exec())
```

## 🎨 Step 2: QML Button

Now let’s create a button in QML and connect it to the Python slot.


```q
// main.qml
import QtQuick
import QtQuick.Controls

ApplicationWindow {
    visible: true
    width: 400
    height: 200
    title: "Button Example"

    Button {
        text: "Click Me"
        anchors.centerIn: parent
        onClicked: backend.say_hello()
    }
}
```

When you click the button, it calls `backend.say_hello()` in Python, and you’ll see **“Hello from Python!”** printed in the terminal.

# 📌 PySide6 + QML Styling Buttons Notes

## **Purpose**

- Buttons are core interactive elements in QML.
    
- Styling allows customization of their look and feel to match application design.
    
- Achieved by overriding the `background`, `contentItem`, or using custom components.
    

## **Basic Button**

qml

```python
import QtQuick
import QtQuick.Controls

Button {
    text: "Click Me"
    onClicked: console.log("Button clicked")
}
```

- Default style depends on the platform and Qt Quick Controls theme.
    

## **Custom Background**

qml

```python
Button {
    text: "Styled Button"
    background: Rectangle {
        implicitWidth: 100
        implicitHeight: 40
        color: control.down ? "darkblue" : "blue"
        radius: 6
    }
}
```

- `control.down` → detects pressed state.
    
- `radius` → rounded corners.
    

## **Custom Content**

qml

```python
Button {
    contentItem: Text {
        text: control.text
        color: "white"
        font.bold: true
        horizontalAlignment: Text.AlignHCenter
        verticalAlignment: Text.AlignVCenter
    }
    background: Rectangle {
        color: control.hovered ? "green" : "gray"
        radius: 8
    }
}
```

- `contentItem` → replaces default text rendering.
    
- `hovered` → detects hover state.
    

## **Icon Buttons**

qml

```python
Button {
    text: ""
    contentItem: Image {
        source: "qrc:/icons/settings.png"
        anchors.centerIn: parent
    }
    background: Rectangle {
        color: "transparent"
    }
}
```

- Creates a button with only an icon.
    

## **Flat Buttons**

qml

```python
Button {
    text: "Flat"
    background: Rectangle {
        color: "transparent"
        border.color: "blue"
        border.width: 2
        radius: 4
    }
}
```

- Minimalist style with border only.
    

## **Animated Buttons**

qml

```python
Button {
    text: "Hover Me"
    background: Rectangle {
        id: bg
        color: "blue"
        radius: 6

        Behavior on color {
            ColorAnimation { duration: 200 }
        }
    }
    onHoveredChanged: bg.color = hovered ? "lightblue" : "blue"
}
```

- Smooth color transition on hover.
    

## **Best Practices**

- Use `background` for shape and color customization.
    
- Use `contentItem` for text/icon customization.
    
- Keep hover/pressed states distinct for good UX.
    
- Apply animations sparingly for responsiveness.
    
- Maintain consistent button styles across the app.
