## 📝 Step 1: Python Backend

We’ll expose a Python class with a slot (function) that QML can call when the button is clicked.

In **PySide6** with QML, the `@Slot()` decorator is required for methods you want to call from QML code. Without it, QML won't recognize your Python method as callable, and you’ll get a `TypeError` like: _"Property 'log' of object Logger(...) is not a function"_

```python
# main.py
import sys
from PySide6.QtCore import QObject, Slot
from PySide6.QtGui import QGuiApplication
from PySide6.QtQml import QQmlApplicationEngine

class Backend(QObject):
    @Slot()
    def say_hello(self):
        print("Hello from Python!")

app = QGuiApplication(sys.argv)
engine = QQmlApplicationEngine()

backend = Backend()
# Expose backend to QML as a global object
engine.rootContext().setContextProperty("backend", backend)

engine.load("main.qml")
if not engine.rootObjects():
    sys.exit(-1)

sys.exit(app.exec())
```

## 🎨 Step 2: QML Button

Now let’s create a button in QML and connect it to the Python slot.


```q
// main.qml
import QtQuick
import QtQuick.Controls

ApplicationWindow {
    visible: true
    width: 400
    height: 200
    title: "Button Example"

    Button {
        text: "Click Me"
        anchors.centerIn: parent
        onClicked: backend.say_hello()
    }
}
```

When you click the button, it calls `backend.say_hello()` in Python, and you’ll see **“Hello from Python!”** printed in the terminal.

## 🎨 Step 3: Styling Buttons

You can customize the look of the button easily:


```q
Button {
    text: "Styled Button"
    anchors.centerIn: parent
    background: Rectangle {
        color: "lightblue"
        radius: 8
    }
    font.pixelSize: 18
}
```

## 🧠 Key Concepts Learned

- **Signals & Slots**: QML’s `onClicked` signal triggers a Python slot.
    
- **Context Properties**: Exposing Python objects to QML.
    
- **Styling**: Buttons can be customized with `background` and font properties.
