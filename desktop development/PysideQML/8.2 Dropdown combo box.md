
# 📌 PySide6 + QML Dropdown Menu Notes

## **Purpose**

- Dropdown menus allow users to select one option from a list.
    
- Implemented using `ComboBox` or `Menu` in QML.
    
- Useful for settings, filters, and navigation.
    

## **Basic ComboBox**

qml

```python
import QtQuick
import QtQuick.Controls

ComboBox {
    model: ["Option A", "Option B", "Option C"]
    onActivated: console.log("Selected:", currentText)
}
```

- `model` → defines the list of options.
    
- `currentText` → returns the selected option.
    
- `onActivated` → signal triggered when selection changes.
    

## **Customizing ComboBox**

- Override `delegate` for custom item appearance:
    

qml

```python
ComboBox {
    model: ["Red", "Green", "Blue"]

    delegate: ItemDelegate {
        text: modelData
        background: Rectangle {
            color: modelData.toLowerCase()
            radius: 4
        }
    }
}
```

- `modelData` → represents each item in the model.
    

## **Menu + MenuItem**

- Alternative dropdown using `Menu`:
    

qml

```python
Menu {
    id: fileMenu
    title: "File"

    MenuItem { text: "New"; onTriggered: console.log("New clicked") }
    MenuItem { text: "Open"; onTriggered: console.log("Open clicked") }
    MenuItem { text: "Exit"; onTriggered: Qt.quit() }
}

Button {
    text: "File"
    onClicked: fileMenu.open()
}
```

- `MenuItem` → defines each option.
    
- `onTriggered` → handles selection.
    

## **Custom Styling**

- Style dropdown background and content:
    

qml

```python
ComboBox {
    model: ["Option 1", "Option 2", "Option 3"]

    contentItem: Text {
        text: control.currentText
        color: "white"
        font.bold: true
        verticalAlignment: Text.AlignVCenter
    }

    background: Rectangle {
        color: "darkblue"
        radius: 6
    }
}
```

- `contentItem` → customizes selected item display.
    
- `background` → customizes dropdown box appearance.
    

## **Best Practices**

- Use `ComboBox` for simple dropdowns.
    
- Use `Menu` for hierarchical or contextual options.
    
- Customize `delegate` for item styling.
    
- Keep dropdowns short (5–7 items max) for usability.
    
- Use icons in `MenuItem` for clarity when needed.
