## 📝 Step 1: Python Backend (Simple List Model)

We’ll expose a list of items to QML, same as before, but now we’ll use it with advanced views.



```python
# main.py
import sys
from PySide6.QtCore import QObject, Signal, Property
from PySide6.QtGui import QGuiApplication
from PySide6.QtQml import QQmlApplicationEngine

class Backend(QObject):
    itemsChanged = Signal()

    def __init__(self):
        super().__init__()
        self._items = ["File A", "File B", "File C"]

    def get_items(self):
        return self._items

    items = Property("QStringList", fget=get_items, notify=itemsChanged)

app = QGuiApplication(sys.argv)
engine = QQmlApplicationEngine()

backend = Backend()
engine.rootContext().setContextProperty("backend", backend)

engine.load("main.qml")
if not engine.rootObjects():
    sys.exit(-1)

sys.exit(app.exec())
```

## 🎨 Step 2: Repeater

`Repeater` creates multiple instances of a component based on a model.

qml

```JavaScript
// main.qml
import QtQuick
import QtQuick.Controls

ApplicationWindow {
    visible: true
    width: 400
    height: 300
    title: "Repeater Example"

    Column {
        anchors.centerIn: parent
        spacing: 10

        Repeater {
            model: backend.items
            delegate: Button {
                text: modelData
                onClicked: console.log("Clicked:", modelData)
            }
        }
    }
}
```

📌 Use case: dynamic buttons, menus, or repeated widgets.

## 🎨 Step 3: GridView

`GridView` arranges items in a grid — perfect for image galleries or dashboards.

qml

```JavaScript
GridView {
    width: parent.width
    height: 200
    cellWidth: 100
    cellHeight: 40
    model: backend.items

    delegate: Rectangle {
        width: 100
        height: 40
        color: "lightblue"
        border.color: "black"

        Text {
            anchors.centerIn: parent
            text: modelData
        }
    }
}
```

📌 Use case: icon grids, product listings.

## 🎨 Step 5: Component Reuse

Define reusable UI blocks with `Component`.

qml

```JavaScript
Component {
    id: fileDelegate
    Rectangle {
        width: 200
        height: 40
        color: "lightgray"
        Text { anchors.centerIn: parent; text: modelData }
    }
}

ListView {
    width: parent.width
    height: 200
    model: backend.items
    delegate: fileDelegate
}
```

📌 Use case: consistent styling across multiple views.

## 🧠 Key Concepts Learned

- **Repeater**: Generate repeated UI elements.
    
- **GridView**: Display items in a grid layout.
    
- **TreeView**: Show hierarchical data.
    
- **Component**: Reusable UI blocks for consistency.
