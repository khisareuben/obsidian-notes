
## 🎯 Step 1: Choose Recommended Fonts

For desktop apps, you want fonts that are:

- Clear and readable
    
- Cross-platform friendly
    
- Free and open-source
    

### Recommended Fonts

- **Roboto** – Modern, clean, widely used.
    
- **Open Sans** – Great for UI text.
    
- **Source Sans Pro** – Designed for interfaces.
    
- **Fira Code** – Perfect if you want monospaced text (great for coding apps).
    

## 📥 Step 2: Download Fonts

1. Visit Google Fonts.
    
2. Search for your chosen font (e.g., Roboto).
    
3. Click **Download family** → You’ll get a `.zip` file.
    
4. Extract it → You’ll see `.ttf` or `.otf` files.
    

## 📂 Step 3: Add Fonts to Your Project

- Create a folder in your project, e.g., `fonts/`.
    
- Place the `.ttf` files inside.
    
- If you use Qt’s resource system, add them to a `.qrc` file:
    
    
    
    ```xml
    <RCC>
      <qresource prefix="/">
        <file>fonts/Roboto-Regular.ttf</file>
        <file>fonts/Roboto-Bold.ttf</file>
      </qresource>
    </RCC>
    ```
    

## 📝 Step 4: Load Fonts in QML

Use `FontLoader` to register fonts:

qml

```JavaScript
FontLoader {
    id: robotoRegular
    source: "qrc:/fonts/Roboto-Regular.ttf"
}

FontLoader {
    id: robotoBold
    source: "qrc:/fonts/Roboto-Bold.ttf"
}

Text {
    text: "Hello Harold"
    font.family: robotoRegular.name
    font.pointSize: 20
}
```

## 🎛️ Step 5: Apply Fonts in Controls

qml

```JavaScript
Button {
    text: "Submit"
    font.family: robotoBold.name
    font.pointSize: 16
    font.bold: true
}
```

## 📊 Step 6: Best Practices

- **Bundle fonts** → Ensures consistency across Linux, Windows, macOS.
    
- **Use stylesheets** → Keep font usage consistent across your app.
    
- **Fallbacks** → Always define a fallback font in case the custom one fails.
    
    qml
    
    ```JavaScript
    font.family: robotoRegular.name ? robotoRegular.name : "Arial"
    ```
