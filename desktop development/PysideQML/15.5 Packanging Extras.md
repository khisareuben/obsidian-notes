# Part 25: Packaging Extras

## 📝 Step 1: Adding an Application Icon

In Python, you can set the app icon so it shows in the taskbar/window.

python

```
# main.py
import sys
from PySide6.QtGui import QGuiApplication, QIcon
from PySide6.QtQml import QQmlApplicationEngine

app = QGuiApplication(sys.argv)

# Set application icon
app.setWindowIcon(QIcon("resources/app_icon.png"))

engine = QQmlApplicationEngine()
engine.load("ui/main.qml")

if not engine.rootObjects():
    sys.exit(-1)

sys.exit(app.exec())
```

📌 Make sure `app_icon.png` is a square image (e.g., 256×256).

## 📝 Step 2: Splash Screen

Show a splash image while the app loads.

qml

```
// ui/main.qml
import QtQuick
import QtQuick.Controls

ApplicationWindow {
    visible: true
    width: 500
    height: 300
    title: "Packaging Extras Example"

    Image {
        id: splash
        anchors.fill: parent
        source: "qrc:/resources/splash.png"
        fillMode: Image.PreserveAspectFit
        opacity: 1.0

        SequentialAnimation on opacity {
            NumberAnimation { from: 1.0; to: 0.0; duration: 2000 }
            running: true
        }
    }

    Label {
        anchors.centerIn: parent
        text: "Main App Loaded"
    }
}
```

📌 The splash fades out after 2 seconds, revealing the main app.

## 📝 Step 3: Embedding Resources with `.qrc`

Qt uses **resource files (**`.qrc`**)** to bundle images, icons, and other assets inside the executable.

xml

```
<!-- resources/qml.qrc -->
<RCC>
    <qresource prefix="/resources">
        <file>app_icon.png</file>
        <file>splash.png</file>
    </qresource>
</RCC>
```

Compile the `.qrc` file into Python:

zsh

```
pyside6-rcc resources/qml.qrc -o resources_rc.py
```

Then import it in `main.py`:

python

```
import resources_rc  # ensures resources are bundled
```

📌 Now you can reference images with `qrc:/resources/...` instead of file paths.

## 📝 Step 4: Packaging with PyInstaller

When you’re ready to distribute:

zsh

```
pyinstaller --onefile --windowed main.py --icon=resources/app_icon.png
```

- `--onefile` → single executable
    
- `--windowed` → no console window
    
- `--icon` → sets app icon
    

## 🧠 Key Concepts Learned

- **Resource System (**`.qrc`**)**: Bundle assets inside the executable.
