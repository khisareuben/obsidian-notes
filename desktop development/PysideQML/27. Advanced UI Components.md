# Part 30: Advanced UI Components

## 📝 Step 1: Creating a Custom Button Component

Instead of repeating button styling everywhere, define a reusable QML component.


```q
// ui/CustomButton.qml
import QtQuick
import QtQuick.Controls

Button {
    id: customBtn
    property color bgColor: "steelblue"
    property color textColor: "white"

    background: Rectangle {
        color: customBtn.bgColor
        radius: 6
    }

    contentItem: Text {
        text: customBtn.text
        color: customBtn.textColor
        font.bold: true
        anchors.centerIn: parent
    }
}
```

📌 You can now use `CustomButton` anywhere in your app with consistent styling.

## 📝 Step 2: Creating a Chart Component

QtQuick has `QtCharts` for visualizations. Wrap it in a reusable component.


```q
// ui/ChartView.qml
import QtQuick
import QtQuick.Controls
import QtCharts

ChartView {
    width: 400
    height: 300
    antialiasing: true

    LineSeries {
        name: "Revenue"
        XYPoint { x: 1; y: 120 }
        XYPoint { x: 2; y: 150 }
        XYPoint { x: 3; y: 180 }
        XYPoint { x: 4; y: 200 }
    }

    ValueAxis { id: xAxis; min: 0; max: 5 }
    ValueAxis { id: yAxis; min: 100; max: 250 }

    axes: [xAxis, yAxis]
}
```

📌 This creates a reusable chart widget for dashboards.

## 📝 Step 3: Using Components in Main UI


```q
// ui/main.qml
import QtQuick
import QtQuick.Controls

ApplicationWindow {
    visible: true
    width: 600
    height: 400
    title: "Advanced UI Components Example"

    Column {
        anchors.centerIn: parent
        spacing: 20

        CustomButton {
            text: "Click Me"
            bgColor: "darkgreen"
            onClicked: console.log("Custom button clicked")
        }

        ChartView {}
    }
}
```

## 🧠 Key Concepts Learned

- **Custom Components** → Encapsulate styling and behavior.
    
- **Reusability** → Define once, use everywhere.
    
- **QtCharts** → Native charting for dashboards.
    
- **Clean UI** → Separate components into their own `.qml` files.
