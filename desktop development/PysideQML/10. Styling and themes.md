## 📝 Step 1: Python Loader (same as before)



```python
# main.py
import sys
from PySide6.QtGui import QGuiApplication
from PySide6.QtQml import QQmlApplicationEngine

app = QGuiApplication(sys.argv)
engine = QQmlApplicationEngine()
engine.load("main.qml")

if not engine.rootObjects():
    sys.exit(-1)

sys.exit(app.exec())
```

## 🎨 Step 2: Basic Styling in QML

You can style controls directly with properties like `color`, `font`, and `background`.



```q
// main.qml
import QtQuick
import QtQuick.Controls

ApplicationWindow {
    visible: true
    width: 400
    height: 300
    title: "Styling Example"

    Column {
        anchors.centerIn: parent
        spacing: 15

        Button {
            text: "Styled Button"
            font.pixelSize: 18
            background: Rectangle {
                color: "lightblue"
                radius: 10
            }
        }

        Label {
            text: "Custom Label"
            font.pixelSize: 20
            color: "darkgreen"
        }
    }
}
```

## 🎨 Step 3: Using Themes (Light/Dark)

Qt Quick Controls 2 supports built‑in themes. You can set them globally.

qml

```q
ApplicationWindow {
    visible: true
    width: 400
    height: 300
    title: "Theme Example"

    // Set dark theme
    Material.theme: Material.Dark
    Material.accent: Material.Blue

    Column {
        anchors.centerIn: parent
        spacing: 10

        Button { text: "Dark Mode Button" }
        Label { text: "Dark Mode Label" }
    }
}
```

Available themes:

- `Material.Light`
    
- `Material.Dark`
    
- `Material.System` (follows OS setting)
    

## 🎨 Step 4: Custom Stylesheets

You can define reusable styles with `Component`.

qml

```q
Component {
    id: styledButton
    Button {
        font.pixelSize: 16
        background: Rectangle {
            color: "orange"
            radius: 8
        }
    }
}

Column {
    anchors.centerIn: parent
    spacing: 10

    styledButton { text: "OK" }
    styledButton { text: "Cancel" }
}
```

## 🧠 Key Concepts Learned

- **Direct styling**: Customize controls with properties.
    
- **Themes**: Use Material/Universal styles for consistent look.
    
- **Accent colors**: Apply brand colors globally.
    
- **Reusable components**: Define styles once and reuse them.
