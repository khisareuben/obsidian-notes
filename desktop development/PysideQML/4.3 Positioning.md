
# 📌 PySide6 + QML Positioning Notes

## **Anchors**

- Simplest way to position items relative to each other or the parent.
    
- Properties:
    
    - `anchors.top`, `anchors.bottom`, `anchors.left`, `anchors.right`
        
    - `anchors.centerIn`, `anchors.fill`
        
- Example:
    
    qml
    
    ```python
    Rectangle {
        width: 200; height: 200
        color: "lightgray"
    
        Image {
            source: "qrc:/icons/logo.png"
            anchors.centerIn: parent
        }
    }
    ```
    

## **Margins**

- Used with anchors to add spacing.
    
- Example:
    
    qml
    
    ```python
    Image {
        source: "qrc:/icons/logo.png"
        anchors.top: parent.top
        anchors.left: parent.left
        anchors.margins: 10
    }
    ```
    

## **Positioning with x/y**

- Direct placement using coordinates.
    
- Example:
    
    qml
    
    ```python
    Image {
        source: "qrc:/icons/logo.png"
        x: 50
        y: 100
    }
    ```
    

## **Layouts**

- Use `Row`, `Column`, `Grid` for automatic positioning.
    
- Example:
    
    qml
    
    ```python
    Row {
        spacing: 10
        Image { source: "qrc:/icons/logo.png" }
        Image { source: "qrc:/icons/background.jpg" }
    }
    ```
    

## **Alignment**

- Inside layouts, use `Layout.alignment`.
    
- Example:
    
    qml
    
    ```python
    Row {
        spacing: 10
        Image {
            source: "qrc:/icons/logo.png"
            Layout.alignment: Qt.AlignHCenter
        }
    }
    ```
    

## **Parent-relative positioning**

- Position items relative to parent dimensions.
    
- Example:
    
    qml
    
    ```python
    Image {
        source: "qrc:/icons/logo.png"
        x: parent.width - width - 10
        y: parent.height - height - 10
    }
    ```
    

## **Best Practices**

- Prefer **anchors** for flexible layouts.
    
- Use **layouts** for dynamic UI with multiple items.
    
- Avoid hardcoding `x`/`y` unless necessary.
    
- Combine anchors + margins for clean spacing.
