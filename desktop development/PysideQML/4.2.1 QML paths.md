# QML: `Qt.resolvedUrl()`

## 🔹 What it is

- `Qt.resolvedUrl(relativePath)` is a **helper function** in QML.
    
- It resolves a **relative path** into an **absolute URL** based on the location of the current QML file.
    
- Ensures that resources (images, audio, sub-QML files) load correctly regardless of the app’s working directory.
    

## 🔹 Why use it

- **Avoids path issues** when running your app from different directories.
    
- **Keeps code portable** — relative paths are automatically converted to absolute URLs.
    
- **Recommended** for referencing assets in QML projects.
    

## 🔹 Syntax



```JavaScript
Qt.resolvedUrl("relative/path/to/resource")
```

Returns a `QUrl` string that QML can use for `source` or similar properties.

## 🔹 Example usage

qml

```JavaScript
Image {
    source: Qt.resolvedUrl("images/logo.png")
}
```

If the QML file is in `/home/harold/app/ui/Main.qml`, this resolves to: `file:///home/harold/app/ui/images/logo.png`

## 🔹 Comparison with direct paths

- **Direct relative path**:
    
    qml
    
    ```JavaScript
    Image { source: "images/logo.png" }
    ```
    
    → Works only if the working directory is correct.
    
- **Using** `Qt.resolvedUrl()`:
    
    qml
    
    ```JavaScript
    Image { source: Qt.resolvedUrl("images/logo.png") }
    ```
    
    → Always resolves relative to the QML file itself, not the app’s working directory.
    

## 🔹 Best practices

- Use `Qt.resolvedUrl()` for **local relative assets** (images, sounds, sub-QML files).
    
- Use `qrc:/` for **packaged resources** in `.qrc` files.
    
- Use `file:///` for **absolute paths** (rarely recommended).
    
- Combine with **singleton themes** for centralized asset references.
    

## 🔹 Example: Loading another QML file

qml

```JavaScript
Loader {
    source: Qt.resolvedUrl("SubComponent.qml")
}
```

Ensures the loader finds `SubComponent.qml` relative to the current file.

## 🔹 Summary

- `Qt.resolvedUrl()` = safest way to handle relative paths in QML.
    
- Prevents “file not found” errors caused by working directory differences.
    
- Recommended whenever you reference local resources in QML.
