## 📝 Step 1: Python Backend

For layouts, we don’t need much Python logic yet — just the standard loader.



```python
# main.py
import sys
from PySide6.QtGui import QGuiApplication
from PySide6.QtQml import QQmlApplicationEngine

app = QGuiApplication(sys.argv)
engine = QQmlApplicationEngine()
engine.load("main.qml")

if not engine.rootObjects():
    sys.exit(-1)

sys.exit(app.exec())
```

## 🎨 Step 2: Column Layout

A `Column` arranges items vertically.



```python
// main.qml
import QtQuick
import QtQuick.Controls

ApplicationWindow {
    visible: true
    width: 400
    height: 300
    title: "Column Layout Example"

    Column {
        anchors.centerIn: parent
        spacing: 10

        Label { text: "Name:" }
        TextField { placeholderText: "Enter your name" }

        Label { text: "Email:" }
        TextField { placeholderText: "Enter your email" }

        Button { text: "Submit" }
    }
}
```

## 🎨 Step 4: Grid Layout

A `GridLayout` arranges items in rows and columns.

```JavaScript
GroupBox {
    id: gridBox
    title: "Grid layout"
    Layout.fillWidth: true

    GridLayout {
        id: gridLayout
        rows: 3
        flow: GridLayout.TopToBottom
        anchors.fill: parent
        Label { text: "Line 1" }
        Label { text: "Line 2" }
        Label { text: "Line 3" }

        TextField { }
        TextField { }
        TextField { }

        TextArea {
            text: "This widget spans over three rows in the GridLayout.\n"
                  + "All items in the GridLayout are implicitly positioned from top to bottom."
            Layout.rowSpan: 3
            Layout.fillHeight: true
            Layout.fillWidth: true
        }
    }
}
```

## 🧠 Key Concepts Learned

- **Column**: Vertical stacking of elements.
    
- **Row**: Horizontal stacking of elements.
    
- **Grid**: Table‑like arrangement with rows and columns.
    
- **Spacing**: Controls gaps between elements.
    
- **Anchors**: Used to position layouts relative to parent.


## 🔹 QML Equivalents of a Surface

1. `Item` **(Base visual element)**
    
    - The most fundamental visual building block in QML.
        
    - Acts like a “surface” in that you can place other items inside it, or draw on it.
        
    - Example:
        
    
    
    ```q
    Item {
        width: 200; height: 200
        Rectangle {
            anchors.fill: parent
            color: "lightblue"
        }
    }
    ```
    
2. `Rectangle` **(Basic drawable surface)**
    
    - Often used as a simple surface for backgrounds, borders, or shapes.
        
    - Equivalent to a blank canvas you can paint on.
        
    - Example:
        
    
    
    ```q
    Rectangle {
        width: 300; height: 200
        color: "white"
    }
    ```
    
3. `Canvas` **(Custom drawing surface)**
    
    - Provides a JavaScript API similar to HTML5 Canvas.
        
    - Lets you draw shapes, images, and text programmatically.
        
    - Example:
        
    
    
    ```q
    Canvas {
        width: 300; height: 200
        onPaint: {
            var ctx = getContext("2d")
            ctx.fillStyle = "red"
            ctx.fillRect(10, 10, 100, 100)
        }
    }
    ```
    
4. `QQuickPaintedItem` **(C++/Python side)**
    
    - If you need custom rendering in Python, you subclass this and implement `paint()`.
        
    - This is closer to a “Surface” in native Qt terms, because you’re directly painting with QPainter.
