
# 📌 PySide6 + QML Hover Notes

## **Purpose**

- Hover detection allows UI elements to respond when the mouse pointer enters, moves within, or leaves an area.
    
- Useful for interactive effects like highlighting buttons, tooltips, or animations.
    

## **Enabling Hover**

- Hover events are handled by `MouseArea`.
    
- Must set:
    
    qml
    
    ```python
    hoverEnabled: true
    ```
    
- Without this property, hover signals won’t be triggered.
    

## **Hover Signals**

- `onEntered` → Triggered when the mouse enters the area.
    
- `onExited` → Triggered when the mouse leaves the area.
    
- `onPositionChanged` → Triggered when the mouse moves inside the area.
    

## **Basic Example**

qml

```python
Rectangle {
    width: 100; height: 40; color: "blue"

    MouseArea {
        anchors.fill: parent
        hoverEnabled: true

        onEntered: parent.color = "lightgreen"
        onExited: parent.color = "blue"
    }
}
```

- Changes color when hovered.
    

## **Cursor Shape**

- Change cursor when hovering:
    
    qml
    
    ```python
    MouseArea {
        anchors.fill: parent
        hoverEnabled: true
        cursorShape: Qt.PointingHandCursor
    }
    ```
    

## **Hover + Animations**

- Combine hover signals with animations for smooth effects:
    
    qml
    
    ```python
    Rectangle {
        width: 100; height: 40; color: "blue"
    
        MouseArea {
            anchors.fill: parent
            hoverEnabled: true
    
            onEntered: colorAnim.running = true
            onExited: colorAnim.running = true
        }
    
        ColorAnimation {
            id: colorAnim
            target: parent
            property: "color"
            from: "blue"
            to: "green"
            duration: 300
        }
    }
    ```
    

## **Best Practices**

- Always enable `hoverEnabled` when hover effects are needed.
    
- Use `cursorShape` for better UX feedback.
    
- Combine hover with **animations** or **state changes** for polished UI.
    
- Keep hover effects subtle to avoid distracting users.
