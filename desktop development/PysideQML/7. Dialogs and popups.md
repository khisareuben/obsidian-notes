
# Part 7: Dialogs & Popups in PySide6 + QML

Dialogs are used to interact with users — for confirmations, alerts, or input. Qt Quick provides built‑in dialogs, and you can also design custom ones.

## 📂 Project Structure

Code

```
pyside6_qml_dialogs/
├── main.py

```

## 📝 Step 1: Python Backend



```python
# main.py
import sys
from PySide6.QtCore import QObject, Slot
from PySide6.QtGui import QGuiApplication
from PySide6.QtQml import QQmlApplicationEngine

class Backend(QObject):
    @Slot()
    def confirm_action(self):
        print("User confirmed the action!")

app = QGuiApplication(sys.argv)
engine = QQmlApplicationEngine()

backend = Backend()
engine.rootContext().setContextProperty("backend", backend)

engine.load("main.qml")
if not engine.rootObjects():
    sys.exit(-1)

sys.exit(app.exec())
```

## 🎨 Step 2: MessageDialog

qml

```python
// main.qml
import QtQuick
import QtQuick.Controls
import QtQuick.Dialogs

ApplicationWindow {
    visible: true
    width: 400
    height: 200
    title: "Dialogs Example"

    Button {
        text: "Show Message"
        anchors.centerIn: parent
        onClicked: messageDialog.open()
    }

    MessageDialog {
        id: messageDialog
        title: "Confirmation"
        text: "Do you want to proceed?"
        standardButtons: StandardButton.Yes | StandardButton.No
        onYes: backend.confirm_action()
        onNo: console.log("User cancelled")
    }
}
```

- Clicking **Show Message** opens a dialog.
    
- Choosing **Yes** calls the Python slot.
    
- Choosing **No** logs cancellation.
    

## 🎨 Step 3: FileDialog

qml

```python
FileDialog {
    id: fileDialog
    title: "Select a File"
    nameFilters: ["Text files (*.txt)", "All files (*)"]
    onAccepted: console.log("Selected file:", fileDialog.file)
}
```

Trigger it with a button:

qml

```python
Button {
    text: "Open File"
    onClicked: fileDialog.open()
}
```

## 🎨 Step 4: Custom Popup

qml

```python
Popup {
    id: customPopup
    width: 200
    height: 100
    modal: true
    focus: true

    Rectangle {
        anchors.fill: parent
        color: "lightyellow"
        Text {
            text: "This is a custom popup!"
            anchors.centerIn: parent
        }
    }
}
```

Trigger it:

qml

```python
Button {
    text: "Show Popup"
    onClicked: customPopup.open()
}
```

## 🧠 Key Concepts Learned

- **MessageDialog**: Built‑in confirmation dialog.
    
- **FileDialog**: Lets users select files.
    
- **Popup**: Fully customizable modal window.
    
- **Signals**: Handle user responses (`onYes`, `onNo`, `onAccepted`).
