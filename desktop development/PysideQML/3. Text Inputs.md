## 📝 Step 1: Python Backend

We’ll expose a Python slot that accepts a string from QML.



```python
# main.py
import sys
from PySide6.QtCore import QObject, Slot
from PySide6.QtGui import QGuiApplication
from PySide6.QtQml import QQmlApplicationEngine

class Backend(QObject):
    @Slot(str)
    def process_input(self, user_text):
        print(f"You typed: {user_text}")

app = QGuiApplication(sys.argv)
engine = QQmlApplicationEngine()

backend = Backend()
engine.rootContext().setContextProperty("backend", backend)

engine.load("main.qml")
if not engine.rootObjects():
    sys.exit(-1)

sys.exit(app.exec())
```

## 🎨 Step 2: QML TextField

Here’s a simple text input with a button to send the text to Python.

qml

```python
// main.qml
import QtQuick
import QtQuick.Controls

ApplicationWindow {
    visible: true
    width: 400
    height: 200
    title: "Text Input Example"

    Column {
        anchors.centerIn: parent
        spacing: 10

        TextField {
            id: inputField
            placeholderText: "Type something..."
            width: parent.width * 0.8
        }

        Button {
            text: "Submit"
            onClicked: backend.process_input(inputField.text)
        }
    }
}
```

When you type something and click **Submit**, the text is passed to Python and printed in the terminal.

## 🎨 Step 3: Multi-line Input (TextArea)

For longer text, use `TextArea`.

qml

```python
TextArea {
    id: notes
    placeholderText: "Write your notes here..."
    width: parent.width * 0.8
    height: 100
    wrapMode: Text.Wrap
}
```

You can connect it to Python the same way:

qml

```python
Button {
    text: "Save Notes"
    onClicked: backend.process_input(notes.text)
}
```

## 🧠 Key Concepts Learned

- **TextField**: Single-line input.
    
- **TextArea**: Multi-line input.
    
- **Passing data to Python**: Use `@Slot(str)` to receive strings.
    
- **Binding values**: Access `.text` property in QML.
