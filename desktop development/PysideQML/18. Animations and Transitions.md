## 📝 Step 1: Python Loader (same as before)



```python
# main.py
import sys
from PySide6.QtGui import QGuiApplication
from PySide6.QtQml import QQmlApplicationEngine

app = QGuiApplication(sys.argv)
engine = QQmlApplicationEngine()
engine.load("main.qml")

if not engine.rootObjects():
    sys.exit(-1)

sys.exit(app.exec())
```

## 🎨 Step 2: Property Animation

Animate a property (like position, color, or size).


```q
// main.qml
import QtQuick
import QtQuick.Controls

ApplicationWindow {
    visible: true
    width: 400
    height: 300
    title: "Property Animation Example"

    Rectangle {
        id: box
        width: 100
        height: 100
        color: "red"
        anchors.centerIn: parent

        NumberAnimation on x {
            from: 0
            to: 200
            duration: 2000
            running: true
        }
    }
}
```

📌 The box slides horizontally over 2 seconds.

## 🎨 Step 3: Sequential Animation

Chain multiple animations together.

qml

```python
Rectangle {
    id: circle
    width: 50
    height: 50
    radius: 25
    color: "blue"
    anchors.centerIn: parent

    SequentialAnimation on x {
        NumberAnimation { from: 0; to: 150; duration: 1000 }
        NumberAnimation { from: 150; to: 0; duration: 1000 }
        loops: Animation.Infinite
        running: true
    }
}
```

📌 The circle moves right then left, looping forever.

## 🎨 Step 4: State Changes with Transitions

Define states and animate between them.

qml

```python
Rectangle {
    id: panel
    width: 100
    height: 100
    color: "green"
    anchors.centerIn: parent

    states: [
        State {
            name: "expanded"
            PropertyChanges { target: panel; width: 200; height: 200; color: "orange" }
        }
    ]

    transitions: [
        Transition {
            NumberAnimation { properties: "width,height"; duration: 500 }
            ColorAnimation { property: "color"; duration: 500 }
        }
    ]

    MouseArea {
        anchors.fill: parent
        onClicked: panel.state = panel.state === "" ? "expanded" : ""
    }
}
```

📌 Clicking toggles between normal and expanded state with smooth animation.

## 🎨 Step 5: Behavior for Automatic Animation

Use `Behavior` to animate property changes automatically.

qml

```python
Rectangle {
    id: bar
    width: 50
    height: 20
    color: "purple"

    Behavior on width {
        NumberAnimation { duration: 500 }
    }

    MouseArea {
        anchors.fill: parent
        onClicked: bar.width = bar.width === 50 ? 200 : 50
    }
}
```

📌 Clicking smoothly resizes the bar.

## 🧠 Key Concepts Learned

- **PropertyAnimation**: Animate a single property.
    
- **SequentialAnimation**: Chain animations for complex motion.
    
- **States + Transitions**: Define UI states and animate between them.
    
- **Behavior**: Automatically animate property changes.
