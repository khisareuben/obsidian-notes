
## 📌 Image Handling in PySide6 + QML

### **Image element**

- Basic way to display images in QML.
    
- Example:
    
    qml
    
    ```python
    Image {
        source: "icons/logo.png"
        width: 64
        height: 64
        fillMode: Image.PreserveAspectFit // Image.PreserveAspectCrop, Image.Stretch
    }
    ```
    

### **Qt Resource System**

- Embeds images into the application binary.
    
- Steps:
    
    1. Create a `.qrc` file listing your images.
        
    2. Compile it with `pyside6-rcc`.
        
    3. Use `qrc:/` paths in QML.
        
- Example `.qrc`:
    
    xml
    
    ```python
    <RCC>
      <qresource prefix="/">
        <file>icons/logo.png</file>
      </qresource>
    </RCC>
    ```
    
- Usage in QML:
    
    qml
    
    ```python
    Image { source: "qrc:/icons/logo.png" }
    ```
    

### **SVG support**

- QML can render SVGs directly.
    
- Example:
    
    qml
    
    ```python
    Image {
        source: "icons/vector_icon.svg"
        width: 32
        height: 32
    }
    ```
    

### **Font-based icons**

- Use icon fonts like _Material Icons_ or _Font Awesome_.
    
- Steps:
    
    1. Load font in QML with `FontLoader`.
        
    2. Display icons with `Text`.
        
- Example:
    
    qml
    
    ```python
    FontLoader { id: fa; source: "fonts/fa-solid-900.ttf" }
    
    Text {
        text: "\uf2b9"   // Unicode for icon
        font.family: fa.name
        font.pixelSize: 24
    }
    ```
    

### **Dynamic images**

- Images can be loaded from URLs or generated at runtime.
    
- Example:
    
    qml
    
    ```python
    Image { source: "https://example.com/icon.png" }
    ```
    

### **Best Practices**

- Use **resource system** for portability (no missing files).
    
- Prefer **SVGs** for scalable icons.
    
- Use **icon fonts** for lightweight, consistent styling.
    
- Keep images in a dedicated `icons/` or `assets/` folder.
