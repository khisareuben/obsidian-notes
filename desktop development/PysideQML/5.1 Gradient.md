# 📌 PySide6 + QML Gradient Notes

## **Gradient Basics**

- Gradients are defined inside `Rectangle` or `Item` elements.
    
- Use the `gradient` property with a `Gradient` object.
    
- Example:
    
    qml
    
    ```python
    Rectangle {
        width: 200; height: 200
        gradient: Gradient {
            GradientStop { position: 0.0; color: "red" }
            GradientStop { position: 1.0; color: "blue" }
        }
    }
    ```
    

## **GradientStop**

- Defines a color at a specific position in the gradient.
    
- Properties:
    
    - `position`: value between `0.0` (start) and `1.0` (end).
        
    - `color`: any valid QML color.
        
- Example:
    
    qml
    
    ```python
    GradientStop { position: 0.5; color: "yellow" }
    ```
    

## **Linear Gradient**

- Default gradient type in QML.
    
- Colors blend from top to bottom of the `Rectangle`.
    
- Example:
    
    qml
    
    ```python
    Rectangle {
        width: 200; height: 200
        gradient: Gradient {
            GradientStop { position: 0.0; color: "white" }
            GradientStop { position: 1.0; color: "black" }
        }
    }
    ```
    

## **Radial Gradient**

- Achieved using `RadialGradient` in Qt Quick Shapes (Qt 5.14+).
    
- Example:
    
    qml
    
    ```python
    Shape {
        width: 200; height: 200
        ShapePath {
            strokeWidth: 0
            fillGradient: RadialGradient {
                center: Qt.point(100, 100)
                radius: 100
                GradientStop { position: 0.0; color: "yellow" }
                GradientStop { position: 1.0; color: "green" }
            }
        }
    }
    ```
    

## **Conical Gradient**

- Also available via Qt Quick Shapes.
    
- Colors blend around a center point in a circular sweep.
    
- Example:
    
    qml
    
    ```python
    ShapePath {
        fillGradient: ConicalGradient {
            center: Qt.point(100, 100)
            angle: 0
            GradientStop { position: 0.0; color: "red" }
            GradientStop { position: 1.0; color: "blue" }
        }
    }
    ```
    

## **Best Practices**

- Use **linear gradients** for simple backgrounds.
    
- Use **radial gradients** for spotlight or circular effects.
    
- Keep gradient stops minimal (2–4) for performance.
    
- Prefer **Qt Quick Shapes** for advanced gradient types.
