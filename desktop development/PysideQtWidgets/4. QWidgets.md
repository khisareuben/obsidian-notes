
`QWidget` is a blank window used 10% of the time for thing like pushbox while `QMainWidget` is a window that comes with menubar, titlebar, statusbar sections and is use 90% of the that for applications.


```python
from PySide6.QtWidgets import QApplication, QWidget
import sys
from rockwidget import RockWidget

app = QApplication(sys.argv)

window = RockWidget()
window.show()
app.exec()
```

```python
from PySide6.QtWidgets import QWidget, QPushButton, QHBoxLayout, QVBoxLayout

class RockWidget(QWidget):
    def __init__(self):
        super().__init__()
        self.setWindowTitle("RockWidget")
        button1 = QPushButton("Button1")
        button2 = QPushButton("Button2")

        button_layout = QHBoxLayout()
        button_layout.addWidget(button1)
        button_layout.addWidget(button2)

        self.setLayout(button_layout)
```
