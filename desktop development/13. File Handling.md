## 📝 Step 1: Python Backend — Read & Write Files



```python
# main.py
import sys
from PySide6.QtCore import QObject, Slot, Signal
from PySide6.QtGui import QGuiApplication
from PySide6.QtQml import QQmlApplicationEngine

class Backend(QObject):
    fileContentChanged = Signal(str)

    @Slot(str)
    def open_file(self, path):
        try:
            with open(path, "r", encoding="utf-8") as f:
                content = f.read()
                self.fileContentChanged.emit(content)
        except Exception as e:
            print("Error opening file:", e)

    @Slot(str, str)
    def save_file(self, path, content):
        try:
            with open(path, "w", encoding="utf-8") as f:
                f.write(content)
            print("File saved:", path)
        except Exception as e:
            print("Error saving file:", e)

app = QGuiApplication(sys.argv)
engine = QQmlApplicationEngine()

backend = Backend()
engine.rootContext().setContextProperty("backend", backend)

engine.load("main.qml")
if not engine.rootObjects():
    sys.exit(-1)

sys.exit(app.exec())
```

## 🎨 Step 2: QML UI with FileDialog


```q
// main.qml
import QtQuick
import QtQuick.Controls
import QtQuick.Dialogs

ApplicationWindow {
    visible: true
    width: 500
    height: 400
    title: "File Handling Example"

    Column {
        anchors.centerIn: parent
        spacing: 10

        TextArea {
            id: editor
            width: parent.width * 0.9
            height: 250
            wrapMode: Text.Wrap
        }

        Row {
            spacing: 10

            Button {
                text: "Open File"
                onClicked: openDialog.open()
            }

            Button {
                text: "Save File"
                onClicked: saveDialog.open()
            }
        }
    }

    FileDialog {
        id: openDialog
        title: "Open a Text File"
        nameFilters: ["Text files (*.txt)", "All files (*)"]
        onAccepted: backend.open_file(openDialog.file)
    }

    FileDialog {
        id: saveDialog
        title: "Save File As"
        selectExisting: false
        nameFilters: ["Text files (*.txt)", "All files (*)"]
        onAccepted: backend.save_file(saveDialog.file, editor.text)
    }

    Connections {
        target: backend
        onFileContentChanged: editor.text = fileContent
    }
}
```

## 🧠 Key Concepts Learned

- **FileDialog**: Lets users pick files to open/save.
    
- **Slots with arguments**: Python receives file paths and content.
    
- **Signals**: Python sends file content back to QML.
    
- **TextArea**: Editable multi‑line text field for file content.
