# Part 15: Packaging Apps in PySide6 + QML

## 📂 Project Structure (example app)

Code

```
pyside6_qml_packaging/
├── main.py
├── main.qml
└── requirements.txt
```

## 📝 Step 1: Install Packaging Tools

We’ll use **PyInstaller**, a popular tool for creating executables.

zsh

```
pip install pyinstaller
```

## 📝 Step 2: Create a Spec File (optional)

PyInstaller can be run directly, but for QML apps it’s cleaner to use a `.spec` file. Run once to generate it:

zsh

```
pyinstaller --name MyApp --onefile main.py
```

This creates `MyApp.spec`. You can edit it to include QML files.

## 📝 Step 3: Include QML Files

By default, PyInstaller doesn’t know about your `.qml` files. You must tell it to bundle them. Edit `MyApp.spec`:

python

```
# Inside MyApp.spec
a = Analysis(
    ['main.py'],
    ...
    datas=[('main.qml', '.'), ('page1.qml', '.'), ('page2.qml', '.')],
    ...
)
```

This ensures QML files are copied into the executable bundle.

## 📝 Step 4: Build Executable

zsh

```
pyinstaller MyApp.spec
```

- Output will be in `dist/MyApp/`.
    
- On Linux, you’ll get an executable `MyApp`.
    
- On Windows, you’ll get `MyApp.exe`.
    

## 📝 Step 5: Test the Executable

zsh

```
./dist/MyApp/MyApp
```

It should run without needing Python installed.

## 🧠 Key Concepts Learned

- **PyInstaller**: Tool for bundling Python apps.
    
- **Spec file**: Customizes what files are included.
    
- **datas**: Ensures QML files are packaged.
    
- **dist folder**: Contains the final executable.
    

## ⚡ Pro Tips for Distribution

- Use `--onefile` for a single executable, or omit it for faster startup (but multiple files).
    
- Test on a clean machine to ensure dependencies are bundled.
    
- For cross‑platform builds, you must build on each target OS (Linux, Windows, macOS).
