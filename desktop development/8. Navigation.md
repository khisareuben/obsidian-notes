

# Part 8: Navigation (StackView & Multi‑Page Apps)

## 📂 Project Structure

Code

```
pyside6_qml_navigation/
├── main.py
├── main.qml
├── page1.qml
└── page2.qml
```

## 📝 Step 1: Python Backend

For navigation, we don’t need much Python logic yet — just the loader.

python

```
# main.py
import sys
from PySide6.QtGui import QGuiApplication
from PySide6.QtQml import QQmlApplicationEngine

app = QGuiApplication(sys.argv)
engine = QQmlApplicationEngine()
engine.load("main.qml")

if not engine.rootObjects():
    sys.exit(-1)

sys.exit(app.exec())
```

## 🎨 Step 2: Main QML with StackView

`StackView` manages multiple pages and allows pushing/popping them.

qml

```
// main.qml
import QtQuick
import QtQuick.Controls

ApplicationWindow {
    visible: true
    width: 500
    height: 300
    title: "Navigation Example"

    StackView {
        id: stack
        anchors.fill: parent
        initialItem: Qt.resolvedUrl("page1.qml")
    }
}
```

## 🎨 Step 3: Page 1

This page has a button to navigate to Page 2.

qml

```
// page1.qml
import QtQuick
import QtQuick.Controls

Page {
    title: "Page 1"

    Column {
        anchors.centerIn: parent
        spacing: 10

        Label { text: "This is Page 1" }

        Button {
            text: "Go to Page 2"
            onClicked: stack.push(Qt.resolvedUrl("page2.qml"))
        }
    }
}
```

## 🎨 Step 4: Page 2

This page has a button to go back.

qml

```
// page2.qml
import QtQuick
import QtQuick.Controls

Page {
    title: "Page 2"

    Column {
        anchors.centerIn: parent
        spacing: 10

        Label { text: "This is Page 2" }

        Button {
            text: "Back to Page 1"
            onClicked: stack.pop()
        }
    }
}
```

## ▶️ Step 5: Run the App

zsh

```
python main.py
```

- The app starts on **Page 1**.
    
- Clicking **Go to Page 2** loads Page 2.
    
- Clicking **Back to Page 1** returns to Page 1.
    

## 🧠 Key Concepts Learned

- **StackView**: Manages navigation between pages.
    
- **Page**: A container for each screen.
    
- **push()**: Moves forward to a new page.
    
- **pop()**: Goes back to the previous page.
    
- **initialItem**: Defines the starting page.



# 🔄 Passing Arguments with StackView

## 📂 Project Structure

Code

```
pyside6_qml_navigation_args/
├── main.py
├── main.qml
├── page1.qml
└── page2.qml
```

## 📝 Step 1: Python Loader (same as before)

python

```
# main.py
import sys
from PySide6.QtGui import QGuiApplication
from PySide6.QtQml import QQmlApplicationEngine

app = QGuiApplication(sys.argv)
engine = QQmlApplicationEngine()
engine.load("main.qml")

if not engine.rootObjects():
    sys.exit(-1)

sys.exit(app.exec())
```

## 🎨 Step 2: Main QML with StackView

qml

```
// main.qml
import QtQuick
import QtQuick.Controls

ApplicationWindow {
    visible: true
    width: 500
    height: 300
    title: "Navigation with Arguments"

    StackView {
        id: stack
        anchors.fill: parent
        initialItem: Qt.resolvedUrl("page1.qml")
    }
}
```

## 🎨 Step 3: Page 1 — Passing Data

qml

```
// page1.qml
import QtQuick
import QtQuick.Controls

Page {
    title: "Page 1"

    Column {
        anchors.centerIn: parent
        spacing: 10

        Label { text: "Enter your name:" }

        TextField {
            id: nameField
            placeholderText: "Type name here"
            width: 200
        }

        Button {
            text: "Go to Page 2"
            onClicked: {
                stack.push(Qt.resolvedUrl("page2.qml"), { userName: nameField.text })
            }
        }
    }
}
```

Here, when we push Page 2, we also pass an **object** `{ userName: nameField.text }`.

## 🎨 Step 4: Page 2 — Receiving Data

qml

```
// page2.qml
import QtQuick
import QtQuick.Controls

Page {
    title: "Page 2"

    property string userName: ""   // receive argument

    Column {
        anchors.centerIn: parent
        spacing: 10

        Label {
            text: "Welcome, " + userName
            font.pixelSize: 20
        }

        Button {
            text: "Back to Page 1"
            onClicked: stack.pop()
        }
    }
}
```

Notice the `property string userName: ""`. When Page 2 is pushed, QML automatically assigns the passed argument to this property.

## ▶️ Step 5: Run the App

zsh

```
python main.py
```

- On Page 1, type a name (e.g., _Harold_).
    
- Click **Go to Page 2**.
    
- Page 2 will display: **“Welcome, Harold”**.
    

## 🧠 Key Concepts Learned

- **Arguments in StackView**: You can pass data when pushing a new page.
    
- **Properties**: Pages define properties to receive arguments.
    
- **Binding**: Passed values are automatically bound to those properties.
